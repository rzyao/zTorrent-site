# Forum UI 设计规范

## 1. 业务特性

- **布局**: 主打多栏布局（分类、主题列表、内容区）。
- **组件**: 包含复杂的编辑器 (`Composer`) 和交互操作（点赞、回复）。

## 2. 视觉特征

- **排版**: 更加注重文字的可读性，使用更大的行高 (`leading-relaxed`)。
- **颜色**: 通常使用更加柔和的背景色，区分引用块和普通正文。

## 3. 核心组件

- 位于 `@/modules/forum/components/ui/`。
- 强调发帖编辑器 (`Composer`) 的全屏/悬浮体验。

## 4. 性能要求

- 瀑布流/无限滚动展示主题列表。
- 局部刷新（回复后直接插入 DOM）。
