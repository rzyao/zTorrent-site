# 读取前端项目的文档

当你处理前端项目时，必须遵循以下步骤：

1.  **识别文档**: 定位项目中的文档目录（通常是 `docs/`）或根目录下的 Markdown 文件。
2.  **强制阅读**: 在进行任何实质性修改前，使用 `view_file` 读取 `architecture.md`, `ui-components.md`, `coding-style.md` 等核心文件。
3.  **遵循规范**: 确保你的修改逻辑与文档中定义的架构和组件规范完全一致。
