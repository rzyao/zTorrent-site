# Admin 模块交互与视觉规范 (Design System)

本文档旨在统一 Admin 管理后台的交互逻辑与视觉风格，核心原则是**“上下文决定样式”**。

---

## 1. 按钮交互规范 (Button Actions & Styles)

按钮的样式不应随意选择，必须根据**操作的语义**和**所处的上下文**严格对应。

### 1.1 核心操作映射表

| 操作类型 (Action) | 上下文 (Context)    | 推荐组件样式 (Prop)          | 视觉表现      | 示例                  |
| :---------------- | :------------------ | :--------------------------- | :------------ | :-------------------- |
| **新建 / 添加**   | 页面/Toolbar (主要) | `<Button variant="primary">` | **蓝底白字**  | [添加用户] [新建角色] |
| **新建 / 添加**   | 列表/行内 (次要)    | `<Button variant="dashed">`  | **虚线边框**  | [ + 添加规则]         |
| **保存 / 提交**   | 表单底部            | `<Button variant="primary">` | **蓝底白字**  | [保存修改] [提交审核] |
| **取消 / 返回**   | 表单底部            | `<Button variant="default">` | **白底灰框**  | [取消] [返回列表]     |
| **删除 / 销毁**   | 任意位置            | `<Button danger>`            | **红字/红框** | [删除]                |
| **编辑 / 修改**   | 表格行内            | `<Button variant="link">`    | **蓝色文字**  | [编辑]                |
| **查看详情**      | 表格行内            | `<Button variant="link">`    | **蓝色文字**  | [详情]                |
| **更多操作**      | 表格行内            | `<Button variant="link">`    | **蓝色文字**  | [...]                 |
| **批量操作**      | 表格 Toolbar        | `<Button variant="default">` | **白底灰框**  | [批量删除] [导出]     |

### 1.2 详细场景说明

#### A. 页面主要操作区 (Page Toolbar)

位于表格上方或页面右上角，用于放置页面级的核心操作。

- **主操作**（如“添加角色”）：**必须**使用 `variant="primary"` (蓝色)。
- **次操作**（如“导出”、“批量操作”）：使用 `variant="default"` (白底)。

```tsx
// ✅ 正确示例：Toolbar
<div className="flex gap-2">
  <Button variant="primary" icon={<Plus />}>
    新建用户
  </Button>
  <Button variant="default" icon={<Download />}>
    导出数据
  </Button>
</div>
```

#### B. 表格行内操作列 (Table Actions)

位于表格的“操作”列中。

- **所有操作**：**必须**使用 `variant="link"` (链接样式)。
- **原因**：避免表格中出现大量边框和色块，保持界面清爽。
- **危险操作**：叠加 `danger` 属性 (红色文字)。

```tsx
// ✅ 正确示例：表格操作列
<div className="flex justify-center gap-1">
  <Button variant="link" icon={<Edit />}>
    编辑
  </Button>
  <Button variant="link" icon={<Shield />}>
    授权
  </Button>
  <Button variant="link" danger icon={<Trash />}>
    删除
  </Button>
</div>
```

#### C. 弹窗/表单底部 (Modal Footer)

- **确认/提交**：`variant="primary"` (蓝色)。
- **取消/关闭**：`variant="default"` (白底)。

## 2. 标签色彩规范 (Tag Colors)

**核心原则：颜色即语义。** 相同含义的状态在全站必须使用相同的颜色，严禁使用随机颜色。

### 2.1 颜色映射表 (Color Mapping)

| 语义大类              | 推荐颜色 (Prop)   | 视觉效果   | 典型应用场景                           |
| :-------------------- | :---------------- | :--------- | :------------------------------------- |
| **技术标识 (ID/Key)** | `geekblue`        | **极客蓝** | 角色 Key (`admin`)、权限编码、Order ID |
| **成功 / 正常**       | `success`         | 绿色       | 状态：已启用、支付成功、运行正常       |
| **进行中 / 处理**     | `processing`      | 蓝色       | 状态：正在下载、审核中、连接中         |
| **警告 / 异常**       | `warning`         | 金色       | 状态：待处理、资源不足、连接超时       |
| **错误 / 禁止**       | `error`           | 红色       | 状态：已禁用、支付失败、被封禁         |
| **未开始 / 默认**     | `default`         | 灰色       | 状态：草稿、离线、未知                 |
| **营销 / 活动**       | `magenta`         | 品红       | 优惠券、限时活动                       |
| **金额 / 等级**       | `gold` / `orange` | 金/橘      | VIP 等级、费率、积分                   |

### 2.2 样式变体使用 (Variants)

Tag 组件提供三种样式变体 (`type` 属性)，需根据场景严格选择：

1.  **Filled (默认)**: 浅色背景 + 浅色边框。
    - ✅ **最佳实践**: 90% 的场景应使用此样式（如列表页的状态展示）。
2.  **Outlined**: 透明背景 + 深色边框。
    - ✅ **适用**: 次级信息，或在背景色较深时使用。
3.  **Solid**: 深色实心背景 + 白色文字。
    - ⚠️ **慎用**: 仅用于极少数需要**强强调**的场景（如：未读数徽标）。禁止在表格中大量使用，以免造成视觉疲劳。

### 2.3 禁忌 (Don'ts)

- ❌ **禁止**对同一状态使用不同的颜色（如：一会用 Green 表示"启用"，一会用 Blue）。
- ❌ **禁止**使用 Solid 样式作为列表常态，这会导致页面像"牛皮癣"广告。
- ❌ **禁止**在标识符 (如 Key/ID) 上使用除了 `geekblue` 或 `default` 之外的颜色。

## 3. 字体与排版规范 (Typography)

**核心原则：保持克制。** 绝大多数文本应使用默认字号和默认字重，除非用户同意，否则不能加粗或改变字号。

### 3.1 字体使用约束 (Constraints)

- **默认状态**: 所有文本默认使用标准字号 (`text-sm` / 14px) 和标准字重 (`font-normal` / 400)。
- **严禁随意加粗**:
  - ❌ **禁止**为了"强调"而随意使用 `font-bold` 或 `font-semibold`。
  - ✅ 仅限页面一级标题 (`h1`)、表头 (`th`) 使用加粗。
  - ✅ 列表中的关键实体名称（如用户名）可使用 `font-medium`，但严禁使用 bold。
- **严禁随意改字号**:
  - ❌ **禁止**随意使用 `text-lg`, `text-xl` 等大字号。
  - ✅ 仅限页面标题可使用 `text-2xl`，Dialog 标题可使用 `text-lg`。
  - 其余所有内容一律保持 `text-sm`。

### 3.2 对齐方式

- **表格文本列**: 左对齐 (text-left)。
- **表格数值列**: 右对齐 (text-right)，并使用等宽字体 (font-mono)。
- **表格操作列**: **必须居中对齐** (text-center, align="center")。
- **表单标签**: 右对齐或顶部对齐。

### 3.3 标题规范

- **页面标题**: `text-2xl font-semibold`
- **卡片/弹窗标题**: `text-lg font-medium`
- **正文/表格内容**: `text-sm font-normal` (默认)

---

## 4. 间距与布局 (Spacing)

- **两个按钮之间**: `gap-2` (8px)。
- **表格操作列按钮之间**: `gap-1` (4px)。
- **页面内容与边缘**: `p-6` (24px)。
- **Section 之间**: `space-y-6` (24px)。
