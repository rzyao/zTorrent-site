# 首页推荐功能 - 前端接口对接文档

> 生成日期: 2025-12-15
> 关联对话: 首页推荐功能开发
> 更新记录: 增加 Tab 导航管理相关接口

## 1. 功能概述

本次开发实现了首页推荐系统的后端支持，引入了**二级导航 (Tab)** 机制。

1. 管理员可配置首页的 Tab（如“全站”、“电影”、“剧集”），支持关联基础分类或作为全站聚合。
2. 推荐板块（Config）与 Tab 为**多对多**关系，一个推荐板块可同时挂载在多个 Tab 下。
3. 用户端首页接口改为按 Tab 分组返回数据。

## 2. 接口清单

所有接口均使用 **POST** 请求，参数通过 **Body** 传递。

### 2.1 Tab 管理接口

| 接口名称          | 路径                           | 权限   | 描述                |
| :---------------- | :----------------------------- | :----- | :------------------ |
| 创建 Tab          | `/recommendations/create-tab`  | 管理员 | 创建首页 Tab        |
| 更新 Tab          | `/recommendations/update-tab`  | 管理员 | 更新 Tab 信息       |
| 删除 Tab          | `/recommendations/delete-tab`  | 管理员 | 删除 Tab            |
| Tab 列表 (管理端) | `/recommendations/list-tabs`   | 管理员 | 列出所有 Tab        |
| Tab 列表 (用户端) | `/recommendations/active-tabs` | 公开   | 获取启用的 Tab 列表 |

### 2.2 推荐配置接口

| 接口名称     | 路径                                | 权限   | 描述                         |
| :----------- | :---------------------------------- | :----- | :--------------------------- |
| 创建推荐配置 | `/recommendations/create-config`    | 管理员 | 创建新的推荐板块，需关联 Tab |
| 更新推荐配置 | `/recommendations/update-config`    | 管理员 | 更新配置（包括关联的 Tabs）  |
| 删除推荐配置 | `/recommendations/delete-config`    | 管理员 | 移除推荐板块                 |
| 配置列表     | `/recommendations/list-ops-configs` | 管理员 | 列出所有配置                 |

### 2.3 用户端聚合接口

| 接口名称         | 路径                       | 权限 | 描述                                    |
| :--------------- | :------------------------- | :--- | :-------------------------------------- |
| 首页默认数据     | `/recommendations/index`   | 公开 | 返回默认 Tab 分组的推荐数据 |
| 获取单个板块内容 | `/recommendations/content` | 公开 | 单独加载某个板块内容（如需懒加载）      |

## 3. 接口详情

### 3.1 Tab 管理

#### 3.1.1 创建/更新 Tab

**路径**: `/recommendations/create-tab` 或 `/recommendations/update-tab`

**请求参数**:
| 字段名 | 类型 | 必填 | 描述 | 示例 |
| :--- | :--- | :--- | :--- | :--- |
| `id` | `string` | Update 必填 | Tab ID | |
| `label` | `string` | ✅ | Tab 显示名称 | `"电影"` |
| `categoryKey` | `string` | ❌ | 关联的基础分类 Key，`null` 或不传表示“全站” | `"movie"` |
| `sort` | `number` | ❌ | 排序权重（大号在前） | `100` |
| `enabled` | `boolean` | ❌ | 是否启用 | `true` |
| `icon` | `string` | ❌ | 图标标识 | `"FilmIcon"` |

---

### 3.2 推荐配置管理

#### 3.2.1 创建/更新配置

**路径**: `/recommendations/create-config` 或 `/recommendations/update-config`

**请求参数变化**:
相较于旧版，移除了 `categoryKey`，改为 `tabIds`。

| 字段名      | 类型       | 必填 | 描述                                            | 示例                           |
| :---------- | :--------- | :--- | :---------------------------------------------- | :----------------------------- |
| `title`     | `string`   | ✅   | 板块标题                                        | `"本周最热"`                   |
| `tabIds`    | `string[]` | ✅   | **关联的 Tab ID 列表**                          | `["tab_uuid_1", "tab_uuid_2"]` |
| `type`      | `enum`     | ✅   | 策略: `latest`, `hot_downloads`, `hot_views`... | `"hot_downloads"`              |
| `timeRange` | `number`   | ❌   | 时间范围（天）                                  | `7`                            |
| ...         | ...        | ...  | 其他字段同前                                    |                                |

---

### 3.3 首页默认推荐

硬编码【电影】分组到二级导航，默认展示【电影】分组。

**路径**: `POST /recommendations/index`

**描述**: 返回默认 【电影】分组的推荐数据。

**响应示例**:

```json
{
  "code": 1000,
  "message": "ok",
  "data": [
    {
      "tab": {
        "id": "tab_1",
        "label": "全站",
        "categoryKey": null,
        "sort": 100
      },
      "sections": [
        {
          "config": {
            "id": "cfg_1",
            "title": "全站热门",
            "type": "hot_downloads"
          },
          "items": [{ "id": "t1", "title": "..." }]
        }
      ]
    },
    {
      "tab": {
        "id": "tab_2",
        "label": "电影",
        "categoryKey": "movie",
        "sort": 90
      },
      "sections": [
        {
          "config": {
            "id": "cfg_1",
            "title": "全站热门",
            "type": "hot_downloads"
          },
          "items": [{ "id": "t2", "title": "仅电影类的热门..." }]
        }
      ]
    }
  ]
}
```

> **注意**:
>
> 1. 上例中，同一个配置 `cfg_1`（全站热门）同时关联了 Tab 1 和 Tab 2。
> 2. 在 Tab 1 (全站) 下，它展示所有类型的热门种子。
> 3. 在 Tab 2 (电影) 下，系统会自动应用 `categoryKey=movie` 过滤，只展示电影类的热门种子。

## 4. 数据模型

### 4.1 RecommendationTab (推荐标签)

| 字段          | 类型      | 描述                    |
| :------------ | :-------- | :---------------------- |
| `id`          | `string`  | UUID                    |
| `label`       | `string`  | 显示名                  |
| `categoryKey` | `string?` | 关联分类，`null` 为全站 |
| `sort`        | `number`  | 排序                    |
| `enabled`     | `boolean` | 状态                    |
| `icon`        | `string?` | 图标                    |

### 4.2 RecommendationConfig (推荐配置)

| 字段    | 类型                  | 描述                  |
| :------ | :-------------------- | :-------------------- |
| `id`    | `string`              | UUID                  |
| `title` | `string`              | 标题                  |
| `tabs`  | `RecommendationTab[]` | **多对多关联的 Tabs** |
| `type`  | `string`              | 策略                  |
| ...     | ...                   | ...                   |

## 5. 前端开发建议

1. **首页布局**: 建议使用 `Tabs` 组件作为顶层容器。
2. **数据渲染**:
   - 请求 `/recommendations/index`。
   - 遍历 `data` 数组生成 Tabs。
   - 在每个 Tab Panel 中，遍历 `sections` 数组渲染推荐板块。
3. **懒加载优化**: 如果 Tab 数量多，可考虑只渲染首个 Tab 的内容，其他 Tab 切换时再通过接口（需后端支持按 TabID 获取，目前后端是一次性返回，如需优化请反馈）或前端隐藏显示。
   - _当前后端实现为一次性返回所有启用的 Tab 及其内容，适合数据量不大的场景。_
