# 内容模型重构变更说明

> **版本**: v2.0  
> **日期**: 2024-12-18  
> **状态**: ✅ 已完成

## 概述

本次重构将原有的 `Film`（影片）模型拆分为 `Movie`（电影）和 `Series`（剧集）两个独立模型，以更精确地表达内容类型。

### 核心变更

- 🎬 `Film` 模型 → `Movie`（电影）+ `Series`（剧集）
- 📺 新增 `Episode`（单集）实体
- 📋 `Playlist` 支持混合内容（电影 + 剧集）
- 🔗 `Torrent` 支持多类型关联

---

## API 变更

### 新增端点

#### Movies 模块

| 端点             | 方法 | 说明             |
| ---------------- | ---- | ---------------- |
| `/movies/create` | POST | 创建电影         |
| `/movies/update` | POST | 更新电影         |
| `/movies/delete` | POST | 删除电影         |
| `/movies/detail` | POST | 获取电影详情     |
| `/movies/list`   | POST | 电影列表（分页） |

#### Series 模块

| 端点             | 方法 | 说明                       |
| ---------------- | ---- | -------------------------- |
| `/series/create` | POST | 创建剧集                   |
| `/series/update` | POST | 更新剧集                   |
| `/series/delete` | POST | 删除剧集                   |
| `/series/detail` | POST | 获取剧集详情（含单集列表） |
| `/series/list`   | POST | 剧集列表（分页）           |

#### Playlists 模块（新增）

| 端点                       | 方法 | 说明                       |
| -------------------------- | ---- | -------------------------- |
| `/playlists/add-item`      | POST | 添加内容项（movie/series） |
| `/playlists/remove-item`   | POST | 移除内容项                 |
| `/playlists/items/list`    | POST | 获取片单内容列表           |
| `/playlists/reorder-items` | POST | 重排序内容项               |

### 废弃端点

| 原端点                   | 替代方案                   |
| ------------------------ | -------------------------- |
| `/films/*`               | `/movies/*` 或 `/series/*` |
| `/playlists/add-film`    | `/playlists/add-item`      |
| `/playlists/remove-film` | `/playlists/remove-item`   |
| `/playlists/reorder`     | `/playlists/reorder-items` |

## 前端迁移指南

### 1. 更新 API 调用

```typescript
// ❌ 旧代码
import { FilmsService } from "./api/films";
FilmsService.filmsControllerList();
FilmsService.filmsControllerCreate(dto);

// ✅ 新代码
import { MoviesService, SeriesService } from "./api";
MoviesService.moviesControllerList(); // 电影
SeriesService.seriesControllerList(); // 剧集
```

### 2. 更新枚举引用

```typescript
// ❌ 旧代码
CategoryKind.Film;
UserCategoryType.Film;

// ✅ 新代码
CategoryKind.Movie; // 电影分类
CategoryKind.Series; // 剧集分类
```

### 3. 片单内容操作

```typescript
// ❌ 旧代码
PlaylistsService.addFilm({ playlistId, filmId });

// ✅ 新代码
PlaylistsService.addItem({
  playlistId,
  itemType: "movie", // 或 'series'
  itemId,
});
```

### 4. 处理响应数据

```typescript
// 片单内容列表响应
interface PlaylistItem {
  id: string;
  itemType: "movie" | "series";
  itemId: string;
  title: string;
  posterUrl: string;
  year: string;
  rating: number;
  // series 特有
  seasonNumber?: number;
  episodeCount?: number;
}
```

## 数据迁移

> [!IMPORTANT]
> 迁移脚本位于 `.gemini/data-migration.sql`

### 执行步骤

1. **备份数据库**
2. 执行 `UPDATE categories SET kind = 'movie' WHERE kind = 'film'`
3. 执行 `UPDATE user_categories SET type = 'movie' WHERE type = 'film'`
4. 执行 Film → Movie 数据迁移
5. 执行 playlist_films → playlist_items 迁移
6. 执行 torrents 关联更新
7. **验证数据完整性**

### 可删除的旧数据表

迁移验证通过后，可执行：

```sql
DROP TABLE IF EXISTS film_torrents;
DROP TABLE IF EXISTS film_categories;
DROP TABLE IF EXISTS playlist_films;
DROP TABLE IF EXISTS films;
```

> [!CAUTION]
> 删除表操作不可逆，请确保迁移完成且验证通过后再执行。
