# 编辑页面后端对接规格文档（数据库与API设计）

## 文档目的与范围
- 覆盖“影片编辑”“片单编辑”两大功能的后端落地方案：数据库表结构、实体关系、API契约、DTO与校验、权限与审计、错误码、索引与性能建议。
- 与现有OpenAPI风格保持一致（统一响应包裹、POST方法为主、`/entity/action` URL风格、`FilmsService/TorrentsService` 命名规范）。

## 数据库设计
- 目标：在满足当前前端表单字段的基础上，保持可扩展与可索引，且能与既有 `Torrents` 等实体平滑对接。

- 表：`films`
  - 字段：
    - `id uuid pk`
    - `title varchar(256) not null`
    - `original_title varchar(256)`
    - `year varchar(32)`（示例支持 `2011-2019`）
    - `category enum('film','series','documentary','anime') default 'film'`
    - `rating decimal(3,1) default 0.0`
    - `duration varchar(64)`（如 `169分钟` 或 `全8季73集`）
    - `director varchar(256)`
    - `description text`
    - `poster_url varchar(512)`
    - `backdrop_url varchar(512)`
    - `enabled boolean default true`
    - `sort int default 0`
    - `created_at timestamptz not null`
    - `updated_at timestamptz not null`

- 表：`genres`
  - 字段：`id uuid pk`、`name varchar(64) unique not null`
  - 关系表：`film_genres(film_id uuid fk -> films.id, genre_id uuid fk -> genres.id)`，唯一 `(film_id, genre_id)`

- 可选表：`persons` 与 `film_cast`
  - `persons(id, name)`；`film_cast(film_id, person_id)` 多对多
  - 若暂不需要可用 `films.cast jsonb` 代替，后续再归一化

- 表：`torrents`（复用既有）
  - 关联表：`film_torrents(film_id uuid fk, torrent_id uuid fk, sort int default 0)`；唯一 `(film_id, torrent_id)`

- 表：`playlists`
  - 字段：
    - `id uuid pk`
    - `title varchar(256) not null`
    - `description text`
    - `cover_url varchar(512)`
    - `visibility enum('public','private','friends') default 'public'`
    - `owner_user_id uuid not null`
    - `views int default 0`
    - `likes int default 0`
    - `enabled boolean default true`
    - `sort int default 0`
    - `created_at timestamptz not null`
    - `updated_at timestamptz not null`
  - 关系表：`playlist_films(playlist_id uuid fk, film_id uuid fk, sort int default 0)`；唯一 `(playlist_id, film_id)`

- 索引建议：
  - `films(title)`、`films(director)` 建全文索引；`film_genres(genre_id)` 普通索引
  - `film_torrents(film_id, torrent_id)` 唯一索引；`playlist_films(playlist_id, sort)` 排序辅助索引

## API契约与DTO
- 通用要求：所有接口需登录；编辑操作需权限位 `page:edit` 或更细粒度（例如：`film:write`、`playlist:write`）。统一响应包裹 `{ code, message, data, path, timestamp }`。

### 影片（扩展 FilmsService）
- `POST /films/create-film`
  - 请求体 `CreateFilmDto`（扩展）：
  ```json
  {
    "title": "星际穿越",
    "description": "...",
    "coverUrl": "https://.../poster.jpg",
    "enabled": true,
    "sort": 0,
    "originalTitle": "Interstellar",
    "year": "2014",
    "category": "film",
    "rating": 9.8,
    "duration": "169分钟",
    "director": "克里斯托弗·诺兰",
    "posterUrl": "https://...",
    "backdropUrl": "https://...",
    "genres": ["科幻","剧情","冒险"],
    "cast": ["马修·麦康纳","安妮·海瑟薇"]
  }
  ```
  - 响应：`data: { id: "uuid" }`

- `POST /films/update-film`
  - 请求体：`{ id: "uuid", data: UpdateFilmDto }`（字段同上全部可选）
  - 响应：`data: { id: "uuid", updatedAt: "2025-11-28T..." }`

- `POST /films/delete-film`
  - 请求体：`{ id: "uuid" }`
  - 响应：`data: { success: true }`

- `POST /films/list-films`
  - 请求体：`{ page, limit, keyword?, filters? }`，其中 `filters` 示例：`{ category, year, ratingMin, ratingMax, genreIds[] }`
  - 响应：
  ```json
  {
    "code": 0,
    "message": "ok",
    "data": {
      "items": [
        {"id":"...","title":"...","originalTitle":"...","year":"2014","category":"film","rating":9.8,"posterUrl":"...","torrentCount":3}
      ],
      "total": 123,
      "page": 1,
      "limit": 20
    },
    "path": "/films/list-films",
    "timestamp": "..."
  }
  ```

- `POST /films/get-film`
  - 请求体：`{ id: "uuid" }`
  - 响应 `FilmDetail`：包含 `genres[]`、`cast[]`、`torrents[]`

- `POST /films/film-add-torrent`
  - 请求体：`{ filmId: "uuid", torrentId: "uuid", sort?: 0 }`
  - 响应：`data: { filmId, torrentId }`

- `POST /films/update-film-torrent`
  - 请求体：`{ id: "filmTorrentRelId"|"torrentId", data: { sort?: 0 } }`
  - 响应：`data: { updated: true }`

- `POST /films/film-remove-torrent`
  - 请求体：`{ filmId: "uuid", torrentId: "uuid" }`
  - 响应：`data: { success: true }`

### 种子（TorrentsService 供编辑页使用）
- `POST /torrents/create`
  - 请求体：
  ```json
  {
    "version": "4K HDR REMUX 国英双语",
    "size": "68.5 GB",
    "quality": "2160p",
    "source": "BluRay",
    "codec": "H.265",
    "audio": "Dolby Atmos",
    "isFree": true,
    "isVip": false,
    "uploadDate": "2024-11-10"
  }
  ```
  - 响应：`data: { id: "uuid" }`

- `POST /torrents/update` → `{ id, data }`
- `POST /torrents/delete` → `{ id }`
- `POST /torrents/list` → 支持分页与关键词，用于选择已有版本

### 片单（新增 PlaylistsService）
- `POST /playlists/create-playlist`
  - 请求体：
  ```json
  {
    "title": "诺兰电影全集",
    "description": "...",
    "coverUrl": "https://...",
    "visibility": "public",
    "enabled": true,
    "sort": 0
  }
  ```
  - 响应：`data: { id: "uuid" }`

- `POST /playlists/update-playlist` → `{ id, data }`
- `POST /playlists/delete-playlist` → `{ id }`
- `POST /playlists/list-playlists` → `{ page, limit, keyword?, visibility?, ownerUserId? }`
- `POST /playlists/get-playlist` → `{ id }`，返回 `PlaylistDetail`（含 `movies[]`）
- `POST /playlists/add-film` → `{ playlistId, filmId, sort? }`
- `POST /playlists/remove-film` → `{ playlistId, filmId }`
- `POST /playlists/reorder-film` → `{ playlistId, filmId, sort }`
- 可选统计：`POST /playlists/increment-views`、`POST /playlists/like`

## DTO抽象
- `FilmSummary`: `{ id, title, originalTitle?, year?, category?, rating?, posterUrl?, torrentCount }`
- `FilmDetail`: `FilmSummary + { backdropUrl?, duration?, director?, description?, genres[], cast[], torrents[] }`
- `PlaylistSummary`: `{ id, title, coverUrl?, visibility, views, likes }`
- `PlaylistDetail`: `PlaylistSummary + { description?, movies: FilmSummary[] }`

## 校验规则
- 影片：`title` 必填；`year` 允许 `YYYY` 或 `YYYY-YYYY`；`rating` 0–10；`category` 枚举；`genres[]/cast[]` 长度限制（如≤20）；URL校验。
- 种子：`version/quality/source/codec/audio` 必填；`size` 统一格式；`isFree/isVip` 布尔。
- 片单：`title` 必填；`visibility` 枚举；`sort` 非负整数；去重校验。
- 服务端统一返回 `422` 表示字段校验失败，`409` 表示关系重复或冲突。

## 权限与审计
- 权限位：`page:edit`；删除类接口建议独立权限位（如 `film:delete`、`playlist:delete`）。
- 审计：记录操作者、时间、IP；可选软删除（`deleted_at`）。

## 前端交互映射
- 影片保存：创建→`/films/create-film`；编辑→`/films/update-film`
- 添加版本：不存在则 `torrents/create` → `films/film-add-torrent`；存在则直接绑定
- 移除版本：`films/film-remove-torrent`
- 片单保存：创建→`/playlists/create-playlist`；编辑→`/playlists/update-playlist`
- 片单增删与排序：`add/remove/reorder-film`

## 错误码与返回示例
- 错误码：`400/401/403/404/409/422/500`
- 返回示例遵循统一包裹结构与分页格式（见上节示例）

## 索引与性能建议
- 列表接口默认分页，支持关键词与多条件过滤；
- 文本检索字段建立合适索引；关系表保持唯一约束防止重复绑定。

## OpenAPI与SDK
- 后端完成后更新OpenAPI描述，生成前端SDK：`FilmsService/PlaylistsService/TorrentsService` 对齐方法签名与路径。

## 落地步骤（后端）
1. 建表与迁移：`films/genres/film_genres/film_torrents/playlists/playlist_films(+ 可选 persons/film_cast)`
2. 扩展服务：完善 `FilmsService`；新增 `PlaylistsService`；复用 `TorrentsService`
3. 鉴权中间件：登录校验 + 权限位校验；删除动作为强化权限控制
4. DTO与校验器：按上文字段与规则实现（含枚举与格式校验）
5. OpenAPI更新：生成前端SDK，联调并完成前端替换本地状态

## 设计理由（关键决策）
- 扩展 `Film` 字段以完整映射前端表单，避免额外“扩展表”带来的复杂度；`genres/cast` 允许先行JSON存储，后续归一化。
- 使用关系表 `film_torrents/playlist_films` 保证排序与去重，并便于做联合查询与统计。
- 采用统一响应包裹与错误码，保持与既有服务一致，降低前后端对接成本。
- 权限位细分删除类动作，降低误操作风险并满足审计需求。
