# 产品需求文档：动态路由管理后台 (Route Management Dashboard)

## 1. 项目背景与目标

为 zTorrent-site 系统构建一个可视化的路由管理中心，取代传统的硬编码路由配置方式。旨在赋予超级管理员对系统菜单结构、页面访问权限及组件绑定的完全控制能力，实现“配置即生效”的动态化管理。

## 2. 核心用户角色

| 角色           | 权限            | 核心诉求                                                                                       |
| :------------- | :-------------- | :--------------------------------------------------------------------------------------------- |
| **超级管理员** | 读写删/导入导出 | 能够直观地查看整站菜单结构，快速调整菜单顺序，为新功能配置访问权限，以及在不同环境间迁移配置。 |

## 3. 功能模块详情

### 3.1 路由可视化树 (Route Tree Explorer)

- **展示形式**: 左侧侧边栏展示无限层级树形结构。
- **节点信息**: 显示路由名称、路径(`path`)、图标（如有）、可见性状态(`isVisible`)、启用状态(`isEnabled`)。
- **交互能力**:
  - **展开/折叠**: 支持点击三角图标展开子节点。
  - **选中即编辑**: 点击节点本身，右侧详情面板自动加载该节点数据。
  - **拖拽排序**: 支持拖拽节点进行同级排序调整（自动调用后端 `sort` 接口）。
  - **层级调整**: 支持将节点拖拽改为另一个节点的子节点（自动更新 `parentId`）。

### 3.2 详情编辑面板 (Details Editor Panel)

- **位置**: 界面右侧，与路由树左右分栏布局。
- **字段管控**:
  - **基础信息**: `RouteKey` (只读/唯一), `Path` (必填), `Name` (必填)。
  - **组件绑定 (Smart Select)**:
    - **交互**: 下拉选择框 (Select)。
    - **数据源**: 读取前端 `componentRegistry` 或维护一份静态映射表。
    - **兜底**: 支持手动输入文本以应对新组件未注册的情况。
  - **布局设置**: 下拉选择 `AppLayout` / `AdminLayout` / `ForumLayout` / `None`。
  - **状态开关**: `IsVisible` (显示/隐藏), `IsEnabled` (启用/禁用)。
  - **权限配置 (Permission Picker)**:
    - **交互**: 多选下拉框 (Multi-Select) 或 穿梭框 (Transfer)。
    - **数据源**: 从后端获取所有可用权限列表（需确认是否有权限列表 API，若无则支持手动输入 Tag）。
- **操作栏**:
  - **保存**: 提交修改（`Update` 接口）。
  - **重置**: 恢复到未修改状态。

### 3.3 敏感操作管控

- **删除节点**:
  - **触发**: 详情面板底部“删除”按钮或树节点右键菜单。
  - **逻辑**: 若节点包含子节点，弹出**高风险警告**（“此操作将级联删除 X 个子路由，是否确认？”）。需二次确认。
- **禁用节点**:
  - **逻辑**: 设置 `IsEnabled: false` 时，提示用户该操作会导致所有子路由在前端不可见。

### 3.4 批量管理工具 (Import/Export Tools)

- **入口**: 页面顶部工具栏“批量操作”按钮。
- **功能**:
  - **JSON 编辑器**: 集成 Monaco Editor，支持 JSON 语法高亮与格式校验。允许用户直接粘贴 JSON 进行覆盖导入。
  - **文件导入**: 支持上传 `.json` 配置文件。
  - **导出备份**: 一键下载当前全量路由配置为 `.json` 文件。
- **安全机制**: 导入前进行格式预校验；提交时弹出二次确认框，提示“全量覆盖风险”。

## 4. 用户路径 (User Flows)

### Flow 1: 调整菜单顺序

1. 管理员进入“路由管理”页面。
2. 在左侧树中找到目标菜单项。
3. 鼠标按住节点拖拽至目标位置（出现辅助线提示）。
4. 松开鼠标，前端自动发起排序请求。
5. 成功提示弹出，界面保持新顺序。

### Flow 2: 新增受限页面

1. 点击“新建路由”按钮（需选择父节点，或默认为根节点）。
2. 右侧面板清空。
3. 填写 Path (`/admin/audit`)，选择 Component (`AuditPage`)。
4. 在“权限配置”中勾选 `audit:view` 和 `audit:edit`。
5. 点击保存。系统自动创建并刷新左侧树。

### Flow 3: 环境迁移 (开发 -> 生产)

1. 在开发环境点击“导出配置”，获得 `routes_dev.json`。
2. 登录生产环境，点击“批量导入”。
3. 上传 `routes_dev.json`。
4. 系统校验 JSON 格式通过。
5. 弹出“确认覆盖”警告，管理员点击确认。
6. 界面自动刷新，新路由生效。

## 5. UI/UX 规范建议

- **布局**: 经典的 master-details 布局（左树右表）。
- **反馈**: 所有保存/删除操作均需 Toast 提示成功/失败。
- **状态标识**: 被隐藏 (`isVisible: false`) 的节点在树中应半透明显示；被禁用 (`isEnabled: false`) 的节点应有删除线或灰色显示。

## 6. 技术依赖

- **前端组件库**: Shadcn UI (Tree, Form, Dialog, Dropdown, Toast).
- **代码编辑器**: `@monaco-editor/react` (用于 JSON 编辑)。
- **图标库**: Lucide React.
