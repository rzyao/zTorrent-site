# 回帖引用图片显示与限制验证

## 验证目标
- 引用块中的 Markdown/HTML 图片正常显示。
- 引用块图片最大高度 160px，宽度不超过容器，保持比例不变。
- 正文区图片显示不受影响。

## 验证步骤
1. 在某回帖中引用包含 `![](http...)` 的图片，查看引用块：
   - 图片应显示且高度≤160px，宽度≤容器宽度。
2. 在回帖中引用 `<img src="http...">` 的图片，查看引用块：
   - 图片同样显示并受限高度与宽度。
3. 使用非 `http(s)` 的图片地址（如 `javascript:...`）：
   - 引用块应显示“图片链接不安全或无效”的提示文本。
4. 检查正文区：
   - 正文区图片仍按原样显示，不受 160px 限制。

## 注意事项
