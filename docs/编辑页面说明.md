# 编辑页面说明文档

## 概述
- 编辑页面用于站点内容的维护与管理，当前包含“影片编辑”和“片单编辑”两个子页签。
- 入口路径为 `/edit`，受登录态保护，默认在统一布局 `AppLayout` 下渲染。
- 当前所有保存/更新操作基于前端本地状态处理，尚未接入后端 API。

## 路由与访问控制
- 路由挂载：`src/routes/AppRoutes.tsx:306-315` 将 `path="/edit"` 映射到 `EditPage` 并包裹 `AuthRoute`。
- 访问入口：顶部导航 `src/layouts/Header.tsx:22` 提供 `<NavLink to="/edit">编辑</NavLink>`。
- 统一布局：`AppLayout` 在 `AppRoutes.tsx:310-312` 中包裹编辑页面，保证一致的头部与容器样式。

## 页面结构
- 容器页面：`src/pages/edit/EditPage.tsx:6-46`
  - 左侧二级导航切换子页签：`activeTab` 为 `'movie' | 'playlist'`。
  - 右侧内容区域根据 `activeTab` 条件渲染 `EditMoviePage` 或 `EditPlaylistPage`。

## 影片编辑页（EditMoviePage）
- 文件位置：`src/pages/edit/EditMoviePage.tsx`
- 核心数据模型：
  - `Movie`：标题、原名、年份、海报、背景、类别、类型数组、评分、时长、导演、演员、简介、`torrents`、`createdAt`、`updatedAt`（`EditMoviePage.tsx:43-60`）。
  - `Torrent`：版本、大小、清晰度、来源、编码、音频、做种/下载数、上传日期、是否 FREE/VIP（`EditMoviePage.tsx:28-41`）。
- 主要状态：
  - `movies` 列表（初始示例数据，`EditMoviePage.tsx:63-183`）。
  - `selectedMovie` 当前选中影片（`EditMoviePage.tsx:185`）。
  - `isEditing`/`isCreating` 编辑态与创建态（`EditMoviePage.tsx:186-187`）。
  - `movieForm` 影片表单（`EditMoviePage.tsx:191-206`）。
  - `torrentForm` 种子表单（`EditMoviePage.tsx:207-217`）。
- 关键交互：
  - 新建影片：`handleCreateNew` 初始化表单与创建态（`EditMoviePage.tsx:219-237`）。
  - 编辑影片：`handleEdit(movie)` 将选中数据写入表单（`EditMoviePage.tsx:239-257`）。
  - 保存影片：`handleSaveMovie` 新建或更新本地 `movies` 列表（`EditMoviePage.tsx:259-289`；按钮触发 `EditMoviePage.tsx:710-716`）。
  - 删除影片：`handleDeleteMovie(id)` 本地移除并清理选中态（`EditMoviePage.tsx:291-298`）。
  - 添加种子版本：`handleAddTorrent` 为选中影片追加 `torrent`（`EditMoviePage.tsx:300-327`）。
  - 移除种子版本：`handleRemoveTorrent(torrentId)` 从选中影片的 `torrents` 过滤移除（`EditMoviePage.tsx:329-338`）。
- 搜索与统计：
  - 搜索过滤：`filteredMovies` 基于标题/原名/导演匹配（`EditMoviePage.tsx:340-345`）。
  - 统计卡片：影片总数、类型分布、总种子数展示（`EditMoviePage.tsx:447-476`）。

## 片单编辑页（EditPlaylistPage）
- 文件位置：`src/pages/edit/EditPlaylistPage.tsx`
- 核心数据模型：
  - `Playlist`：标题、描述、封面、可见性、影片数组、创建/更新日期、浏览量、点赞（`EditPlaylistPage.tsx:35-46`）。
  - `Movie` 子项：基础影片信息与关联种子数量（`EditPlaylistPage.tsx:24-33`）。
- 主要状态：
  - `playlists` 列表（初始示例数据，`EditPlaylistPage.tsx:48-149`）。
  - `selectedPlaylist` 当前选中片单（`EditPlaylistPage.tsx:185`）。
  - `isEditing`/`isCreating` 编辑态与创建态（`EditPlaylistPage.tsx:186-187`）。
  - `editForm` 片单表单（`EditPlaylistPage.tsx:191-198`）。
- 关键交互：
  - 新建片单：`handleCreateNew` 初始化表单与创建态（`EditPlaylistPage.tsx:199-209`）。
  - 编辑片单：`handleEdit(playlist)` 将选中数据写入表单（`EditPlaylistPage.tsx:211-221`）。
  - 保存片单：`handleSave` 新建或更新本地 `playlists`（`EditPlaylistPage.tsx:223-251`；按钮触发 `EditPlaylistPage.tsx:599-601`）。
  - 删除片单：`handleDelete(id)` 本地移除并清理选中态（`EditPlaylistPage.tsx:253-260`）。
  - 添加/移除片单影片：`handleAddMovie` 与 `handleRemoveMovie`（若存在，参考文件内对应实现）。

## 状态管理与数据来源
- 现状：所有数据与交互均基于组件内部 `useState` 管理的本地示例数据，无后端持久化。
- 未发现对 `axios`、`fetch` 或 `src/api/services/*` 的调用；编辑页与 OpenAPI 生成的服务层目前未对接。

## 交互流程（用户视角）
- 进入 `/edit` → 左侧选择“影片编辑”或“片单编辑”。
- 列表区选择已有项或点击“添加”按钮进入编辑/创建态。
- 在右侧表单区域填写内容：
  - 影片页可编辑基础信息并在“版本”区域添加/移除种子；
  - 片单页可编辑基础信息并管理所含影片。
- 点击“保存”按钮：当前仅更新前端本地状态，页面即时反馈但不会写入后端。

## 校验与错误处理现状
- 表单必填仅做了最小化限制（如保存按钮在标题为空时禁用，`EditMoviePage.tsx:711`、`EditPlaylistPage.tsx:600`）。
- 删除操作通过 `confirm(...)` 二次确认（`EditMoviePage.tsx:291-293`、`EditPlaylistPage.tsx:253-255`）。
- 暂未有字段级校验提示、服务端错误处理或全局通知机制。

## 与后端对接建议
- 目标：在保存/更新/删除时调用服务层 API，并在成功后同步前端状态。
- 建议步骤：
  1. 在 `src/api/services/` 下新增 `MoviesService` 与 `PlaylistsService`，或复用既有服务结构。
  2. 在 `handleSaveMovie`/`handleDeleteMovie`/`handleAddTorrent`/`handleRemoveTorrent` 中替换为异步请求；成功后更新状态，失败时提示。
  3. 在 `handleSave`/`handleDelete`（片单）中同样接入服务层。
  4. 引入统一的请求态管理与通知（loading/toast），保证交互可感知。
  5. 补充字段级校验（标题/年份/评分/版本必填与格式限制）。

## 扩展与定制建议
- 角色与权限：结合 `PermissionRoute` 按权限开放（参考 `AppRoutes.tsx:300-304` 里的示例注释）。
- 草稿与发布：新增 `status` 字段与草稿保存入口，提高编辑闭环体验。
- 批量操作：支持批量导入/导出影片与片单。
- 图片上传：接入上传组件与文件服务，替换示例图片 URL。
