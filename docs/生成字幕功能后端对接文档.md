# 字幕功能后端对接文档

## 概述
- 基于前端页面 `src/pages/Subtitles` 的现有 UI 与类型定义，整理后端所需接口，严格对齐 UI 展示与交互，不引入 UI 未体现字段。
- 涵盖：列表查询（搜索/语言筛选/排序/分页）、字幕详情、下载、发布上传（multipart）、可选种子列表、统计、点赞与举报。
- 鉴权与限流策略、错误码规范、请求/响应示例均提供。

## 数据模型
依据 `src/pages/Subtitles/types.ts`，后端模型与字段一一对应：

```ts
export interface Subtitle {
  id: string;            // 字幕唯一标识
  name: string;          // 字幕名称（列表/详情展示）
  type: string;          // 字幕类型（SRT/ASS/SSA/SUB）
  language: string;      // 语言显示文案（如“简体中文”、“English”）
  languageCode: string;  // 语言代码（用于筛选展示国旗等：zh/en/jp/kr）
  torrentName: string;   // 关联种子名称（详情展示）
  torrentId: string;     // 关联种子ID（上传选择）
  uploader: string;      // 上传者昵称（列表/详情展示）
  uploadDate: string;    // 上传时间字符串（yyyy-MM-dd HH:mm）
  downloads: number;     // 下载量（列表/详情展示）
  uploads: number;       // 上传量（列表/详情展示）
  rating: number;        // 评分（列表/详情展示）
  reviews: number;       // 评价数量（详情展示）
  verified: boolean;     // 官方认证标识（列表/详情展示）
  description: string;   // 字幕说明（详情展示，可为空）
}

export interface UploadForm {
  name: string;          // 必填：字幕名称
  type: string;          // 必填：字幕类型
  language: string;      // 必填：上传时选择的语言代码（zh/zh-TW/en/jp/kr）
  torrentId: string;     // 必填：关联种子ID
  description: string;   // 选填：说明
  file: File | null;     // 必填：字幕文件（.srt/.ass/.ssa/.sub）
}

export interface TorrentOption {
  id: string;            // 种子ID
  name: string;          // 种子名称
}
```

统计模型（来自 `StatsCards.tsx` 展示）：
- `totalSubtitles`（number）
- `totalDownloads`（number）
- `totalUploads`（number）
- `avgRating`（number，前端可自行 `toFixed(1)` 展示）

## 鉴权
- 使用 `Authorization: Bearer {token}`。
- 访问策略：
  - 无需登录：列表查询、字幕详情、下载、统计、种子选项。
  - 需登录：发布上传、点赞、举报。

## 限流（建议）
- `GET /api/subtitles`：60/分钟
- `GET /api/subtitles/{id}`：60/分钟
- `GET /api/subtitles/{id}/download`：20/分钟
- `GET /api/subtitles/stats`：60/分钟
- `GET /api/torrents/options`：60/分钟
- `POST /api/subtitles`（上传）：10/小时
- `POST /api/subtitles/{id}/like`：30/分钟
- `POST /api/subtitles/{id}/report`：5/小时


## 接口列表

### 列表查询
- 方法与路径：`GET /api/subtitles`
- 说明：按搜索、语言筛选、排序获取分页列表。
- Headers：`Accept: application/json`
- Query 参数：
  - `search`（string，可选）：匹配 `name`/`torrentName`/`uploader`。
  - `language`（string，可选）：`zh`/`en`/`jp`/`kr`；`all` 或不传表示全部。
  - `sortBy`（string，可选）：`latest` | `downloads` | `uploads` | `rating`。
  - `page`（number，可选，默认1）
  - `limit`（number，可选，默认20）
- 响应 200：
  - `data`：`Subtitle[]`
  - `pagination`：`{ total:number, page:number, limit:number, totalPages:number }`
- 错误：400、500
- 示例请求：
  - `curl "https://api.example.com/api/subtitles?search=Interstellar&language=zh&sortBy=downloads&page=1&limit=20"`
- 示例响应：

### 下载
- 方法与路径：`GET /api/subtitles/{id}/download`
- 说明：下载字幕文件；返回二进制流，并在服务端计数 `downloads`。
- Headers：`Accept: application/octet-stream`
- 响应 200：文件二进制（`Content-Type: application/octet-stream`；`Content-Disposition: attachment; filename="<name>.<ext>"`）
- 错误：404、429、500
- 示例请求：`curl -L "https://api.example.com/api/subtitles/1/download" -o "Interstellar.2014.srt"`

### 发布上传（multipart）
- 方法与路径：`POST /api/subtitles`
- 说明：发布新字幕。
- Headers：
  - `Authorization: Bearer {token}`
  - `Content-Type: multipart/form-data`
- Body（multipart）：
  - `file`（必填）：`.srt/.ass/.ssa/.sub`
  - `name`（必填）：string
  - `type`（必填）：`SRT` | `ASS` | `SSA` | `SUB`
  - `language`（必填）：`zh` | `zh-TW` | `en` | `jp` | `kr`
  - `torrentId`（必填）：string
  - `description`（可选）：string
- 响应 201：`Subtitle`（创建后的完整对象）
- 错误：400、401、403、429、500
- 示例请求：
  - `curl -X POST "https://api.example.com/api/subtitles" -H "Authorization: Bearer TOKEN" -F "file=@Interstellar.srt" -F "name=Interstellar.2014.1080p..." -F "type=SRT" -F "language=zh" -F "torrentId=T001" -F "description=时间轴完美匹配BluRay版本"`
- 示例响应：
```json
{
  "id": "S12345",
  "name": "Interstellar.2014.1080p.BluRay.x264.CHT&ENG",
  "type": "SRT",
  "language": "简体中文",
  "languageCode": "zh",
  "torrentName": "星际穿越 Interstellar (2014) 4K HDR REMUX",
  "torrentId": "T001",
  "uploader": "SubMaster",
  "uploadDate": "2025-12-10 10:20",
  "downloads": 0,
  "uploads": 1,
  "rating": 4.9,
  "reviews": 0,
  "verified": false,
  "description": "官方简繁英三语字幕..."
}
```

### 可选种子列表
- 方法与路径：`GET /api/torrents/options`
- 说明：上传表单的种子下拉选项。
- Headers：`Accept: application/json`
- 响应 200：`{ data: TorrentOption[] }`
- 错误：500
- 示例请求：`curl "https://api.example.com/api/torrents/options"`
- 示例响应：
```json
{
  "data": [
    { "id": "T001", "name": "星际穿越 Interstellar (2014) 4K HDR REMUX" },
    { "id": "T002", "name": "盗梦空间 Inception (2010) 4K UHD BluRay" }
  ]
}
```

### 统计
- 方法与路径：`GET /api/subtitles/stats`
- 说明：用于统计卡片展示。
- Headers：`Accept: application/json`
- 响应 200：`{ totalSubtitles:number, totalDownloads:number, totalUploads:number, avgRating:number }`
- 错误：500
- 示例请求：`curl "https://api.example.com/api/subtitles/stats"`
- 示例响应：
```json
{
  "totalSubtitles": 235,
  "totalDownloads": 253420,
  "totalUploads": 10874,
  "avgRating": 4.8
}
```

### 点赞
- 方法与路径：`POST /api/subtitles/{id}/like`
- 说明：点赞当前字幕。UI 未展示点赞计数，响应不返回计数。
- Headers：`Authorization: Bearer {token}`
- 响应 204：No Content
- 错误：401、403、404、429、500
- 示例请求：`curl -X POST "https://api.example.com/api/subtitles/1/like" -H "Authorization: Bearer TOKEN"`

### 举报
- 方法与路径：`POST /api/subtitles/{id}/report`
- 说明：举报当前字幕。UI 无理由输入，不要求 `reason` 等字段。
- Headers：`Authorization: Bearer {token}`
- 响应 204：No Content
- 错误：401、403、404、429、500
- 示例请求：`curl -X POST "https://api.example.com/api/subtitles/1/report" -H "Authorization: Bearer TOKEN"`

## 设计说明（字段与交互映射）
- 列表筛选与排序：
  - `search` 对齐 `Toolbar` 与 `useSubtitlesList`，匹配 `name`/`torrentName`/`uploader`。
  - `language` 对齐 `FilterLanguage`：`all|zh|en|jp|kr`；上传语言单独支持 `zh-TW`（仅在发布表单出现），与列表筛选集合分离。
  - `sortBy` 映射 `SortBy`：`latest`（按 `uploadDate` 降序）、`downloads`、`uploads`、`rating`。
  - 分页通过 `page/limit` 返回标准信息，未引入额外 UI 不可见字段。
- 字幕详情：完整返回 `Subtitle` 模型全部字段，覆盖认证 `verified`、评分与评价 `rating/reviews`、关联种子 `torrentName/torrentId`、说明 `description` 等。
- 下载：二进制流与 `Content-Disposition` 触发下载；服务端计数 `downloads`。
- 发布上传：multipart 字段严格按 `UploadSubtitleModal.tsx` 的必填项；扩展名与类型枚举源自 `<input accept>` 与 `<select>`。
- 可选种子：仅返回 `TorrentOption` 的 `id/name`，对应上传下拉框内容。
- 统计：对齐 `StatsCards.tsx` 展示项。
- 点赞/举报：UI 无输入与计数展示，接口仅接受 `id` 并返回 204。
