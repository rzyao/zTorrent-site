全局状态管理重构
重构原因
用户要求将数据保存到全局状态，使整个应用的任何页面都可以访问和使用这些数据。

架构变更
原架构：

useUserSummary Hook (hooks/) → Header 组件

UserSummaryContext (context/) → 全局 Provider → 所有组件

使用示例
任何组件都可以访问用户统计数据：

import { useUserSummary } from '@/context/UserSummaryContext';
function MyComponent() {
  const { data, isLoading, error, refresh } = useUserSummary();
  if (isLoading) return <div>加载中...</div>;
  if (error) return <div>错误：{error.message}</div>;
  return (
    <div>
      <p>上传量：{formatBytes(data.uploadedBytes)}</p>
      <p>下载量：{formatBytes(data.downloadedBytes)}</p>
      <p>分享率：{data.ratio.toFixed(2)}</p>
      <p>魔力值：{data.bonus}</p>
      <button onClick={refresh}>刷新</button>
    </div>
  );
}
