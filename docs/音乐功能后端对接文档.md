# 音乐功能后端对接文档

> 关联页面：`src/pages/MusicEditPage.tsx`、`src/pages/MusicPage.tsx`、`src/pages/PlayerPage.tsx`
>
> 设计目标：为前端三页的现有交互提供统一、可扩展的后端接口规范，覆盖音乐大厅、编辑管理、播放与媒体、歌单、评论与歌词、相似推荐等功能。

## 统一约定
- Base URL：`/api`
- 认证方式：HTTP 头 `Authorization: Bearer <token>`（未授权返回 401）
- Content-Type：`application/json`；上传使用 `multipart/form-data`
- 时间单位：时长统一采用秒（number），前端自行格式化展示（`PlayerPage.tsx:627-785` 使用秒格式化；`src/pages/PlayerPage.tsx:220-224`）
- ID 类型：字符串（例如 `song-1733812345678`），由后端生成
- 分页参数：`page`（默认 1）、`pageSize`（默认 20）、返回 `total`
- 排序参数：`sortBy`（如 `plays`、`year`）、`order`（`asc`/`desc`）
- 统一响应结构：
  ```json
  { "code": 0, "message": "OK", "data": { ... } }
  ```
  - 失败示例：`{ "code": 401, "message": "Unauthorized" }`
- 错误码：400（参数错误）、401（未认证）、403（无权限）、404（未找到）、409（冲突）、422（校验失败）、429（限流）、500（服务端错误）
- axios 拦截器对接：后端需在 401 时返回明确错误体，前端将清理 token 并跳转登录（参考 `src/api/axiosInterceptors.ts`）。

## 核心数据模型
- Song（单曲）
  ```json
  {
    "id": "string",
    "title": "string",
    "artist": "string",
    "artistId": "string",
    "album": "string",
    "albumId": "string",
    "duration": 245,
    "coverUrl": "https://...",
    "audioUrl": "https://..." ,
    "genre": "流行",
    "year": 2024,
    "plays": 15420,
    "liked": false
  }
  ```
  - 说明：`PlayerPage.tsx`中 `duration` 为 number（秒）（`src/pages/PlayerPage.tsx:28-38`、`220-224`）；`MusicEditPage.tsx`表单中的时长为字符串输入，后端接收时统一转换为秒（`src/pages/MusicEditPage.tsx:501-508`）。
- Artist（歌手）
  ```json
  { "id": "string", "name": "string", "avatarUrl": "https://...", "bio": "string", "country": "string", "debutYear": 2020, "followers": 128000 }
  ```
- Album（专辑）
  ```json
  { "id": "string", "title": "string", "artist": "string", "artistId": "string", "coverUrl": "https://...", "year": 2024, "genre": "流行", "tracks": 12, "description": "string" }
  ```
- Playlist（歌单）
  ```json
  { "id": "string", "title": "string", "description": "string", "coverUrl": "https://...", "songs": [Song], "isOwn": true, "creator": "我" }
  ```
- Comment（评论）
  ```json
  { "id": "string", "songId": "string", "userId": "string", "userName": "string", "content": "string", "likedCount": 123, "createdAt": "2025-12-10T10:00:00Z" }
  ```
- Lyrics（歌词）
  ```json
  { "songId": "string", "language": "zh-CN", "lines": [{ "time": 12.5, "text": "string" }] }
  ```

## 接口分组与定义

### 音乐大厅
- 热门歌曲
  - `GET /api/music/hall/featured-songs`
  - Query：`page`、`pageSize`、`order=desc`、`sortBy=plays`
  - Response：`{ code, message, data: { items: Song[], total } }`
- 精选歌单
  - `GET /api/music/hall/featured-playlists`
  - Response：`{ code, message, data: { items: Playlist[], total } }`
- 热门歌手
  - `GET /api/music/hall/top-artists`
  - Response：`{ code, message, data: { items: Artist[], total } }`
- 最新专辑
  - `GET /api/music/hall/latest-albums`
  - Response：`{ code, message, data: { items: Album[], total } }`

### 单曲（Songs）
- 列表/搜索
  - `GET /api/songs`
  - Query：`q`（标题/歌手/专辑关键词，映射 `MusicEditPage` 搜索：`src/pages/MusicEditPage.tsx:760-771`、`236-243`）、`artistId`、`albumId`、`genre`、`year`、`page`、`pageSize`
  - Response：`{ code, message, data: { items: Song[], total } }`
- 详情
  - `GET /api/songs/{id}`
- 新增
  - `POST /api/songs`
  - Body：
    ```json
    { "title": "string", "artist": "string", "artistId": "string", "album": "string", "albumId": "string", "duration": 245, "genre": "流行", "year": 2024, "coverUrl": "https://...", "audioId": "media-xxx" }
    ```
- 更新
  - `PUT /api/songs/{id}`（同上字段，允许部分字段变更）
- 删除
  - `DELETE /api/songs/{id}`（映射页面删除操作：`src/pages/MusicEditPage.tsx:186-196`）
- 上传音频
  - `POST /api/songs/{id}/audio`
  - FormData：`file`（音频文件，mp3/aac/flac）
  - Response：`{ code, message, data: { audioId, audioUrl } }`
- 上传封面
  - `POST /api/songs/{id}/cover`
  - FormData：`file`（图片文件）
  - Response：`{ code, message, data: { coverUrl } }`
- 点赞/取消点赞
  - `POST /api/songs/{id}/like`、`DELETE /api/songs/{id}/like`
  - 映射点赞交互（`MusicPage.tsx:253-257`、`521-533`、`572-586`；`PlayerPage.tsx:304-307`、`733-741`）

### 歌手（Artists）
- 列表
  - `GET /api/artists`
  - Query：`q`、`country`、`page`、`pageSize`
- 详情
  - `GET /api/artists/{id}`
- 新增
  - `POST /api/artists`
  - Body：`{ "name": "string", "avatarUrl": "https://...", "bio": "string", "country": "string", "debutYear": 2020 }`
- 更新
  - `PUT /api/artists/{id}`
- 删除
  - `DELETE /api/artists/{id}`（映射页面删除：`src/pages/MusicEditPage.tsx:354-359`）

### 专辑（Albums）
- 列表
  - `GET /api/albums`
  - Query：`q`、`artistId`、`year`、`page`、`pageSize`
- 详情
  - `GET /api/albums/{id}`
- 新增
  - `POST /api/albums`
  - Body：`{ "title": "string", "artist": "string", "artistId": "string", "coverUrl": "https://...", "year": 2024, "genre": "流行", "tracks": 12, "description": "string" }`
- 更新
  - `PUT /api/albums/{id}`
- 删除
  - `DELETE /api/albums/{id}`（映射页面删除：`src/pages/MusicEditPage.tsx:410-415`）

### 歌单（Playlists）
- 获取公开歌单列表
  - `GET /api/playlists`
- 获取我的歌单
  - `GET /api/users/me/playlists`
- 创建歌单
  - `POST /api/playlists`
  - Body：`{ "title": "string", "description": "string" }`
  - 映射前端创建：`src/pages/PlayerPage.tsx:310-327`、对话框 `1195-1252`
- 更新歌单信息
  - `PUT /api/playlists/{id}`
- 删除歌单
  - `DELETE /api/playlists/{id}`（映射：`src/pages/PlayerPage.tsx:524-535`、`364-371`）
- 歌单添加歌曲
  - `POST /api/playlists/{id}/songs`
  - Body：`{ "songId": "string" }`
  - 映射添加：`src/pages/PlayerPage.tsx:329-348`、`1263-1335`；`src/pages/MusicPage.tsx:271-281`（占位）
- 歌单移除歌曲
  - `DELETE /api/playlists/{id}/songs/{songId}`（映射：`src/pages/PlayerPage.tsx:609-616`）
- 收藏/取消收藏歌单
  - `POST /api/playlists/{id}/favorite`、`DELETE /api/playlists/{id}/favorite`
  - 映射：`src/pages/MusicPage.tsx:371-387`、`819-835`

### 播放与媒体
- 音频流播放
  - `GET /api/media/songs/{id}/stream?quality=low|medium|high`
  - 返回：`audio/mpeg` 或 `audio/aac`；支持范围请求（断点续播）
  - 映射 `audioUrl` 字段；当前前端为占位（`src/pages/PlayerPage.tsx:71-117`）
- 播放上报（统计播放量）
  - `POST /api/songs/{id}/plays`
  - Body：`{ "sessionId": "string", "device": "web", "playedSeconds": 60 }`
- 进度上报（可选）
  - `POST /api/songs/{id}/progress`
  - Body：`{ "position": 120 }`

### 评论与歌词
- 获取歌词
  - `GET /api/songs/{id}/lyrics?lang=zh-CN`
- 获取评论列表
  - `GET /api/songs/{id}/comments?page=1&pageSize=20`
- 发表新评论
  - `POST /api/songs/{id}/comments`
  - Body：`{ "content": "string" }`
- 点赞/取消点赞评论
  - `POST /api/comments/{id}/like`、`DELETE /api/comments/{id}/like`

### 相似推荐
- `GET /api/songs/{id}/similar`
- Response：`{ code, message, data: { items: Song[] } }`
- 映射：`src/pages/PlayerPage.tsx:1147-1185`

## 对接注意事项
- 前端 `MusicEditPage` 的时长输入为字符串（如 `3:45`，`src/pages/MusicEditPage.tsx:501-508`），后端存储统一为秒；前端在提交前转换或后端解析支持两种格式
- 当前三页为占位数据与本地状态（`src/pages/MusicEditPage.tsx:62-100`、`src/pages/MusicPage.tsx:107-145`、`src/pages/PlayerPage.tsx:64-131`），落地后端后需替换为接口调用
- 图片/音频目前来自 Unsplash 占位；正式对接后使用后端返回的 `coverUrl` 与 `audioUrl`
