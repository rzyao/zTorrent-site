# 剧集分集与种子管理 - 接口需求文档

> 提交日期: 2025-12-18
> 对应页面: 剧集编辑页 (/edit/series), 剧集详情页 (/series/:id)

## 1. 需求概述

当前 `SeriesService` 仅支持剧集（Series）层面的元数据管理（如标题、海报、简介等）。
为了完善剧集功能，前端需要以下扩展能力：

1.  **分集管理**: 支持对每一季每一集（Episode）进行增删改查（如 S01E01 的标题、时长、剧情简介）。
2.  **种子关联**:
    - 支持将种子绑定到“剧集”整体（如全季打包）。
    - 支持将种子绑定到“特定分集”（如单集资源）。
    - 支持查询当前剧集关联的所有种子。

## 2. 建议接口清单

| 模块         | 接口名称         | 建议路径                  | 方法 | 功能描述                                     |
| :----------- | :--------------- | :------------------------ | :--- | :------------------------------------------- |
| **种子管理** | 获取关联种子列表 | `/series/torrents/list`   | POST | 获取指定剧集 ID 绑定的所有种子（含分集关联） |
|              | 绑定种子         | `/series/torrents/bind`   | POST | 将种子关联到剧集或特定分集                   |
|              | 解绑种子         | `/series/torrents/unbind` | POST | 解除关联                                     |
| **分集管理** | 获取分集列表     | `/series/episodes/list`   | POST | 获取指定剧集（可按季筛选）的分集列表         |
|              | 创建分集         | `/series/episodes/create` | POST | 添加新的分集信息                             |
|              | 更新分集         | `/series/episodes/update` | POST | 更新分集信息                                 |
|              | 删除分集         | `/series/episodes/delete` | POST | 删除分集                                     |

## 3. 详细接口定义

### 3.1 种子管理

#### 3.1.1 获取关联种子列表

**建议路径**: `POST /series/torrents/list`

**请求参数 (Request Body)**:

| 字段名     | 类型     | 必填 | 说明                |
| :--------- | :------- | :--- | :------------------ |
| `seriesId` | `string` | Yes  | 剧集 ID             |
| `page`     | `number` | No   | 页码 (默认 1)       |
| `limit`    | `number` | No   | 每页数量 (默认 100) |

**期望响应 (Response Data)**:

```json
{
  "items": [
    {
      "id": "1001",
      "torrentId": 5002,
      "title": "Game.of.Thrones.S01.1080p.BluRay",
      "seasonNumber": 1, // 0 或 null 表示全剧/未区分，1 表示第一季
      "episodeNumber": null, // null 表示整季，1 表示第一集
      "size": "50GB",
      "seeders": 100
    }
  ],
  "total": 1
}
```

#### 3.1.2 绑定种子

**建议路径**: `POST /series/torrents/bind`

**请求参数 (Request Body)**:

| 字段名          | 类型     | 必填 | 说明                                  |
| :-------------- | :------- | :--- | :------------------------------------ |
| `seriesId`      | `string` | Yes  | 剧集 ID                               |
| `torrentId`     | `string` | Yes  | 种子 ID                               |
| `seasonNumber`  | `number` | No   | 季号 (例如 1)。不传代表不限季。       |
| `episodeNumber` | `number` | No   | 集号 (例如 1)。不传代表整季或不限集。 |

---

### 3.2 分集管理

#### 3.2.1 获取分集列表

**建议路径**: `POST /series/episodes/list`

**请求参数**:

| 字段名         | 类型     | 必填 | 说明                     |
| :------------- | :------- | :--- | :----------------------- |
| `seriesId`     | `string` | Yes  | 剧集 ID                  |
| `seasonNumber` | `number` | No   | 按季筛选，不传则返回所有 |

**期望响应**:

```json
{
  "items": [
    {
      "id": "E101",
      "seriesId": "S001",
      "seasonNumber": 1,
      "episodeNumber": 1,
      "title": "Winter Is Coming",
      "overview": "Ned Stark is torn between...",
      "airDate": "2011-04-17",
      "stillUrl": "http://..."
    }
  ],
  "total": 10
}
```

#### 3.2.2 创建/更新分集

**建议路径**: `POST /series/episodes/create` 或 `update` (更新需传 `id`)

**请求参数**:

| 字段名          | 类型     | 必填 | 说明     |
| :-------------- | :------- | :--- | :------- |
| `seriesId`      | `string` | Yes  | 剧集 ID  |
| `seasonNumber`  | `number` | Yes  | 季号     |
| `episodeNumber` | `number` | Yes  | 集号     |
| `title`         | `string` | Yes  | 标题     |
| `overview`      | `string` | No   | 简介     |
| `airDate`       | `string` | No   | 发行日期 |
| `stillUrl`      | `string` | No   | 剧照 URL |

## 4. 实体建议

```typescript
interface SeriesEpisode {
  id: string;
  seriesId: string;
  seasonNumber: number;
  episodeNumber: number;
  title: string;
  originalTitle?: string;
  overview?: string;
  runtime?: number; // 分钟
  airDate?: string;
  stillUrl?: string; // 剧照
  voteAverage?: number;
  createdAt: Date;
  updatedAt: Date;
}
```

## 5. 异常处理

- **绑定冲突**: 如果同一个种子尝试绑定到同一个位置，应返回 `code !== 1000` 或忽略。
- **数据一致性**: 删除 Series 时，应级联删除 Episodes 和种子关联关系。
