# 论坛列表重构产品需求文档 (PRD)

## 1. 项目背景 (Background)

目前的论坛列表采用垂直卡片式布局，信息密度较低，且缺乏对参与者的直观展示。为了提升用户阅读效率，对齐主流论坛（如 V2EX、Discuz!）的使用体验，需将列表重构为高密度的水平列表布局，并针对桌面端和移动端进行差异化适配。

## 2. 核心目标 (Goals)

1.  **提升信息密度**：从“卡片”转变为“列表”，在单屏内展示更多话题。
2.  **增强互动感知**：通过“多头像组”直观展示话题的热度和参与者。
3.  **优化移动体验**：针对小屏设备提供精简的高效视图。

## 3. 用户角色 (User Roles)

- **浏览者 (Viewer)**：希望能快速扫描话题标题、标签和最新状态，筛选感兴趣的内容。

## 4. 功能需求 (Functional Requirements)

### 4.1 列表布局重构 (Layout Redesign) [P0]

#### 4.1.1 通用样式

- **容器**：移除原本的独立卡片圆角和阴影，改为扁平化列表。
- **分割线**：每个话题之间使用 `border-bottom` 分割线。
- **背景色**：
  - 浅色模式：`bg-white`，Hover 时 `bg-gray-50`。
  - 深色模式：`bg-[#0F171E]`, Hover 时 `bg-white/5` (保持与首页一致)。

#### 4.1.2 桌面端视图 (Desktop View)

采用 **三栏式** 布局：

| 区域           | 比例/宽度      | 内容说明                                                                                        |
| :------------- | :------------- | :---------------------------------------------------------------------------------------------- |
| **主要信息区** | Flex (自适应)  | **第一行**：[置顶/精选图标] + [标题] (截断)<br>**第二行**：[分类/标签 Badge] (使用不同颜色区分) |
| **参与者区**   | Fixed (~200px) | **头像组 (Avatar Group)**：显示 5 个头像位 (详见 4.2)。                                         |
| **数据指标区** | Fixed (~150px) | 右对齐展示：<br>`[回复数]` (加粗) / `[浏览量]` (灰色)<br>`[最新活动时间]` (如 "1分钟前")        |

#### 4.1.3 移动端视图 (Mobile View)

采用 **紧凑两栏** 布局：

| 区域            | 说明                                                                                                       |
| :-------------- | :--------------------------------------------------------------------------------------------------------- |
| **左侧 (内容)** | **标题**：多行显示 (最多 2 行)。<br>**标签**：显示在标题下方，缩小字号。                                   |
| **右侧 (状态)** | 垂直堆叠右对齐：<br>1. **[最新回复者头像]** (小尺寸)<br>2. **[回复数]** (高亮显示)<br>3. **[时间]** (灰色) |

### 4.2 头像组显示逻辑 (Avatar Logic) [P1]

列表中的头像组用于反映话题的参与热度，需显示 **5 个** 槽位，逻辑如下：

- **Slot 1 (楼主)**：原始发帖人 (Original Poster)。
- **Slot 2-4 (活跃者)**：该话题下回复最频繁的 3 位用户（去重，不含楼主和最新）。
- **Slot 5 (最新)**：最后一位回复者 (Last Replier)。

_注：若不足 5 人，则按实际人数显示；若只有楼主，仅显示 Slot 1。_

### 4.3 顶部筛选栏优化 (Tab Style) [P1]

- **样式变更**：将原本的“胶囊按钮”样式改为**“文本 + 底部高亮条”**风格。
- **交互**：点击切换筛选维度（最新 / 排行榜 / 热门）。
- **状态**：选中项文本加粗并显示底部色条（Brand Color），未选中项为灰色文本。

### 4.4 数据项调整 [P2]

- **移除**：列表中不再显示“点赞数 (Likes)”。
- **保留**：回复数 (Replies)、浏览量 (Views)、活动时间 (Last Active)。

## 5. 非功能需求 (Non-functional Requirements)

- **主题适配**：所有新组件必须完整支持现有的 `useForumTheme` (Light/Dark) 切换。
- **响应式**：严格遵循 Mobile-First 开发原则，利用 Tailwind 的 `md:` 断点切换布局。
- **性能**：头像图片需使用懒加载或合适尺寸的缩略图，防止列表长滚动时卡顿。

## 6. 验收标准 (Acceptance Criteria)

1.  桌面端列表每行高度紧凑，Hover 效果流畅。
2.  桌面端能正确显示 5 个不同角色的头像，且顺序正确（楼主->活跃->最新）。
3.  移动端布局无横向滚动条，右侧信息对齐整齐。
4.  深色模式下，列表背景色与 Header/Sidebar 协调一致 (`#0F171E`)。
