# 论坛筛选栏重设计需求文档 (PRD)

## 1. 项目背景 (Background)

当前论坛列表页的筛选功能较为基础，且分散在不同区域（排序在列表头，新建按钮在全局导航）。为了对齐主流论坛（如 Discourse）的用户体验，需要重新设计整合筛选、排序与操作入口，提升信息检索效率。

## 2. 核心差异对比 (Comparison)

| 功能点           | 当前状态                    | 期望状态 (Target)                                  |
| :--------------- | :-------------------------- | :------------------------------------------------- |
| **新建话题按钮** | 位于全局顶部导航栏 (Header) | **移至论坛列表页顶部筛选栏**，全局导航栏移除该按钮 |
| **分类筛选**     | 仅依赖 Sidebar 或 URL       | **新增下拉菜单**，支持搜索与层级显示               |
| **标签筛选**     | 仅依赖 URL 或帖子内点击     | **新增下拉菜单**，支持搜索热门标签                 |
| **筛选逻辑**     | 混合逻辑                    | **互斥逻辑** (选分类则清空标签，选标签则清空分类)  |
| **排序切换**     | 简单的 Button Group         | **Tab 切换样式** (最新 / 热门 / 趋势)              |

## 3. 功能需求 (Functional Requirements)

### 3.1 筛选导航栏 (Navigation Components)

在 `ForumList` 顶部区域实现一个新的 toolbar 容器，包含以下元素（从左至右）：

#### A. 类别下拉菜单 (Category Dropdown)

- **触发器**: 显示当前选中的类别名称（默认为 "所有类别"）。
- **下拉内容**:
  - 搜索框：快速过滤类别。
  - 列表项：即使 API 返回扁平数据，若有层级关系应尽量体现（或先做扁平列表）。显示类别名称与颜色块。
- **交互**:
  - 点击项跳转至 `/forum/c/:categoryId`。
  - **互斥行为**: 选择类别时，若当前 URL 包含标签参数，应自动移除标签参数。

#### B. 标签下拉菜单 (Tag Dropdown)

- **触发器**: 显示当前选中的标签名称（默认为 "所有标签"）。
- **下拉内容**:
  - 搜索框：快速过滤标签。
  - 列表项：显示热门标签名称与使用计数（如果 API 支持）。
- **交互**:
  - 点击项跳转至 `/forum/tag/:tagId` (或 `/tag/:tagId`，需确认路由定义)。
  - **互斥行为**: 选择标签时，若当前 URL 包含类别参数（非默认），应自动重置类别为 "all"（即跳转到标签专属页）。

#### C. 排序选项卡 (Sort Tabs)

- **样式**: 文本标签样式（Text Tabs），选中项高亮（加粗或下划线）。
- **选项**:
  - **最新 (Latest)**: 对应 `sortBy=latest`
  - **热门 (Popular)**: 对应 `sortBy=popular`（回复最多）
  - **趋势 (Trending)**: 对应 `sortBy=trending`（近期活跃）
- **交互**: 切换 Tab更新列表数据，但不改变当前的类别/标签筛选上下文。

#### D. 新建话题按钮 (Create Topic Button)

- **位置**: 筛选栏最右侧。
- **样式**: 高亮的主色调按钮，带图标（Plus 或 Pen）。
- **行为**: 跳转至 `/forum/create`。

### 3.2 移动端依然 (Mobile Adaptation)

- **方案**: **1B (保留完整功能)**。
- **布局**:
  - 考虑到屏幕宽度限制，可能需要两行布局：
    - **Row 1**: [类别下拉] [标签下拉] (各占 50% 宽度或自适应)
    - **Row 2**: [排序 Tabs (Scrollable)] [新建按钮 (Icon Only 或 紧凑版)]
  - 或者保持 Flex Wrap，让其自然换行。

## 4. 技术需求 (Technical Requirements)

### 4.1 数据获取

- 需要复用或增强 `useForumsCategories` Hook 获取全量分类列表。
- 需要复用或增强 `useForumsTagsQuery` Hook 获取热门标签列表。

### 4.2 路由变更 (Routing)

- 确保 `ForumLayout` 或 `ForumList` 能正确响应 URL 参数变化（`categoryId`, `tagId`）。
- 现有的路由结构可能需要检查是否支持 `/forum/tag/:tagId` 这种纯标签路由，如果不支持，可能需要调整路由配置。

### 4.3 组件结构建议

- 新建 `src/pages/Forums/components/ForumFilterBar.tsx` 组件，封装上述逻辑，保持 `ForumList.tsx` 简洁。
