# 产品需求文档：论坛类别管理功能

> **版本**: v1.0  
> **创建日期**: 2025-12-30  
> **状态**: 待开发

---

## 1. 项目背景与价值主张

### 1.1 背景

当前论坛系统已具备类别展示功能，但缺少前端管理入口。管理员需要通过后端接口或数据库直接操作才能新增/编辑类别，效率低下且易出错。

### 1.2 价值主张

- **提升运营效率**: 管理员可通过可视化界面快速管理类别
- **降低操作门槛**: 无需技术背景即可配置类别样式
- **统一用户体验**: 延续论坛现有设计风格

---

## 2. 核心用户角色

| 角色         | 描述              | 权限                 |
| ------------ | ----------------- | -------------------- |
| **管理员**   | 论坛运营管理人员  | 新增、编辑、查看类别 |
| **普通用户** | 论坛访客/注册用户 | 仅查看类别列表       |

## 3. 功能模块

### 3.1 功能清单

| 优先级 | 功能名称       | 路由                          | 描述                                       |
| ------ | -------------- | ----------------------------- | ------------------------------------------ |
| **P0** | 新建类别页面   | `/forum/new-category`         | 管理员创建新类别的表单页面                 |
| **P0** | 编辑类别页面   | `/forum/category/{slug}/edit` | 管理员编辑现有类别的表单页面               |

| **P1** | 图标选择器组件 | -                             | Lucide 图标列表选择 UI 组件                |

### 3.2 功能详情

#### 3.2.1 新建类别页面 (`/forum/new-category`)

**页面结构**:

```
┌─────────────────────────────────────────┐
│ ← 返回                      新建类别     │
├─────────────────────────────────────────┤
│                                         │
│  类别名称 *                              │
│  ┌─────────────────────────────────┐    │
│  │ 输入类别名称...                  │    │
│  └─────────────────────────────────┘    │
│                                         │
│  类别描述                               │
│  ┌─────────────────────────────────┐    │
│  │ 输入类别描述...                  │    │
│  │                                 │    │
│  └─────────────────────────────────┘    │
│                                         │
│  主题颜色                               │
│  ┌──────┐                              │
│  │ 🎨   │  #6b7280                     │
│  └──────┘                              │
│                                         │
│  类别图标                               │
│  ┌──────────────────────────────────┐   │
│  │ 🏠 📦 💬 ⚙️ 📚 🎮 ... (可选图标) │   │
│  └──────────────────────────────────┘   │
│                                         │
│  ┌─────────────────────────────────┐    │
│  │           创建类别              │    │
│  └─────────────────────────────────┘    │
│                                         │
└─────────────────────────────────────────┘
```

**表单字段**:

| 字段名   | 字段 Key      | 类型       | 必填 | 默认值    | 说明               |
| -------- | ------------- | ---------- | ---- | --------- | ------------------ |
| 类别名称 | `name`        | 文本输入   | ✅   | -         | 最大 50 字符       |
| 类别描述 | `description` | 多行文本   | ❌   | -         | 最大 500 字符      |
| 主题颜色 | `color`       | 颜色选择器 | ❌   | `#6b7280` | Hex 格式           |
| 类别图标 | `icon`        | 图标选择器 | ❌   | -         | Lucide 图标名      |
| URL 别名 | `slug`        | 自动生成   | -    | -         | 根据 name 自动生成 |
| 排序权重 | `sortOrder`   | 隐藏       | -    | `0`       | 默认值             |
| 是否激活 | `isActive`    | 隐藏       | -    | `true`    | 默认激活           |

**slug 生成规则**:

- 中文: 使用拼音转换 (如 "技术讨论" → "jishu-taolun")
- 英文: 小写 + 空格转连字符 (如 "Tech Talk" → "tech-talk")
- 特殊字符: 移除或替换

#### 3.2.2 编辑类别页面 (`/forum/category/{slug}/edit`)

- 表单字段与新建页面**完全相同**
- 页面加载时从 API 获取类别数据并填充表单
- 标题改为"编辑类别"
- 按钮改为"保存更改"

#### 3.2.3 类别列表页入口修改 (`/forum/categories`)

在页面标题栏右侧添加"新增类别"按钮：

- **可见性**: 仅管理员登录后可见
- **样式**: 与论坛主色调一致 (深色模式 amber，浅色模式 blue)
- **图标**: `Plus` (lucide-react)

## 4. 用户路径 (User Flow)

### 4.1 新建类别流程

```
管理员访问 /forum/categories
         ↓
    看到"新增类别"按钮
         ↓
    点击按钮
         ↓
    跳转到 /forum/new-category
         ↓
    填写表单
    - 输入名称 (必填)
    - 输入描述 (可选)
    - 选择颜色 (可选)
    - 选择图标 (可选)
         ↓
    点击"创建类别"
         ↓
    [API 调用: categoriesControllerCreate]
         ↓
    成功 → 跳转到 /forum/category/{slug}/edit
    失败 → 显示错误提示，留在当前页面
```

### 4.2 编辑类别流程

```
管理员访问 /forum/category/{slug}/edit
         ↓
    [API 调用: categoriesControllerFindBySlug]
         ↓
    表单填充现有数据
         ↓
    修改字段
         ↓
    点击"保存更改"
         ↓
    [API 调用: categoriesControllerUpdate]
         ↓
    成功 → 显示成功提示
    失败 → 显示错误提示
```

## 5. 技术规格

### 5.1 涉及 API

| 操作     | API 方法                         | 端点                              |
| -------- | -------------------------------- | --------------------------------- |
| 创建类别 | `categoriesControllerCreate`     | `POST /forums/categories/create`  |
| 获取类别 | `categoriesControllerFindBySlug` | `POST /forums/categories/by-slug` |
| 更新类别 | `categoriesControllerUpdate`     | `POST /forums/categories/update`  |

### 5.2 权限控制

- 后端 API 已有管理员权限校验
- 前端需判断用户角色，控制按钮显示

### 5.3 新增文件

| 文件路径                                       | 描述                 |
| ---------------------------------------------- | -------------------- |
| `src/pages/Forums/pages/NewCategoryPage.tsx`   | 新建类别页面         |
| `src/pages/Forums/pages/EditCategoryPage.tsx`  | 编辑类别页面         |
| `src/pages/Forums/components/CategoryForm.tsx` | 类别表单组件（复用） |
| `src/components/ui/color-picker.tsx`           | 颜色选择器组件       |
| `src/components/ui/icon-picker.tsx`            | 图标选择器组件       |

### 5.4 路由配置

```tsx
// 在 AppRoutes.tsx 中添加
<Route path="new-category" element={<NewCategoryPage />} />
<Route path="category/:slug/edit" element={<EditCategoryPage />} />
```
