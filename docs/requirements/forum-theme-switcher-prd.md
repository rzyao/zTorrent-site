## 1. 项目背景与价值主张

### 1.1 问题陈述

当前 zTorrent 站点存在**两种截然不同的视觉主题风格**：

| 页面              | 主题风格 | 特征                                 |
| ----------------- | -------- | ------------------------------------ |
| **首页 (Home)**   | 深色主题 | 深灰背景、玻璃拟态卡片、琥珀金高亮色 |
| **论坛 (Forums)** | 浅色主题 | 纯白背景、轻阴影卡片、蓝色高亮色     |

这种风格割裂导致：

- 用户从首页进入论坛时产生**视觉跳跃感**
- 偏好深色模式的用户在论坛体验下降
- 设计系统不统一，后续维护成本增加

### 1.2 目标

- **短期目标**：为论坛页面提供主题切换能力，让用户可以手动选择深色或浅色主题
- **长期价值**：建立可复用的主题配置系统，为未来全站主题统一打下基础

### 1.3 成功指标

| 指标             | 目标值                            |
| ---------------- | --------------------------------- |
| 功能完整性       | 100% 符合验收标准                 |
| 主题切换响应时间 | < 100ms                           |
| 持久化可靠性     | 刷新/重新打开后主题偏好 100% 保留 |

## 2. 用户角色

### 2.1 目标用户

| 角色         | 描述               | 核心诉求                                 |
| ------------ | ------------------ | ---------------------------------------- |
| **普通用户** | 论坛浏览者、发帖者 | 根据个人偏好和使用环境选择舒适的显示主题 |

### 2.2 用户场景

1. **场景 A - 夜间阅读**：用户在深夜浏览论坛，希望切换到深色主题以减少眼睛疲劳
2. **场景 B - 风格偏好**：用户习惯了首页的深色风格，进入论坛后希望保持一致的视觉体验
3. **场景 C - 偏好保持**：用户上次选择了深色主题，今天再次进入论坛时，希望自动应用深色主题

### 3.2 功能详细描述

#### 3.2.1 主题配置系统 (P0)

**目标**：将论坛页面的两套主题样式抽离为可配置的设计令牌 (Design Tokens)

**深色主题设计规范** (复用首页风格)：

| 属性       | Tailwind 类名                     |
| ---------- | --------------------------------- |
| 页面背景   | `bg-gray-900` 或 `bg-neutral-900` |
| 卡片背景   | `bg-neutral-800/40`               |
| 卡片边框   | `border-neutral-700/50`           |
| 主文字色   | `text-white`                      |
| 次要文字   | `text-neutral-400`                |
| 高亮色     | `text-amber-400`                  |
| 悬停高亮   | `hover:text-amber-400`            |
| 分隔线     | `border-neutral-700/50`           |
| 输入框背景 | `bg-neutral-800`                  |
| 输入框边框 | `border-neutral-700`              |
| 按钮主色   | `bg-amber-500 hover:bg-amber-600` |

**浅色主题设计规范** (当前论坛样式)：

| 属性       | Tailwind 类名                   |
| ---------- | ------------------------------- |
| 页面背景   | `bg-gray-50`                    |
| 卡片背景   | `bg-white`                      |
| 卡片边框   | `border-gray-200`               |
| 主文字色   | `text-gray-900`                 |
| 次要文字   | `text-gray-500`                 |
| 高亮色     | `text-blue-600`                 |
| 悬停高亮   | `hover:text-blue-600`           |
| 分隔线     | `border-gray-100`               |
| 输入框背景 | `bg-white`                      |
| 输入框边框 | `border-gray-300`               |
| 按钮主色   | `bg-blue-600 hover:bg-blue-700` |

#### 3.2.2 Header 切换按钮 (P0)

**位置**：论坛 Header 右侧操作区，在通知铃铛按钮之前

**交互设计**：

- **图标**：浅色主题下显示月亮 (Moon) 图标；深色主题下显示太阳 (Sun) 图标
- **点击行为**：切换当前主题，并立即应用新主题
- **悬停效果**：与其他 Header 按钮保持一致的 hover 状态

**UI 参考**：

```
[🔍 搜索框] -------- [☀️/🌙 主题] [🔔 通知] [👤 用户] [发布话题]
```

#### 3.2.3 主题持久化 (P0)

**存储方式**：`localStorage`

**存储键名**：`forum-theme-preference`

**存储值**：`'light'` | `'dark'`

**行为逻辑**：

1. 首次访问时，默认使用浅色主题
2. 用户切换主题后，保存偏好到 localStorage
3. 再次访问论坛页面时，读取并应用已保存的主题偏好

#### 3.2.4 过渡动画 (P1)

**目标**：避免主题切换时的突兀闪烁

**实现方案**：

- 在根容器添加 `transition-colors duration-200` 类
- 或使用 CSS 变量 + `transition` 属性实现平滑过渡

## 4. 技术方案概述

### 4.1 架构设计

```
src/
├── pages/
│   └── Forums/
│       ├── index.tsx              # 论坛主页 (包裹 ThemeProvider)
│       ├── context/
│       │   └── ForumThemeContext.tsx  # 论坛主题 Context
│       ├── hooks/
│       │   └── useForumTheme.ts   # 主题 Hook
│       └── components/
│           ├── Header.tsx         # 添加主题切换按钮
│           ├── ForumList.tsx      # 应用主题样式
│           ├── Sidebar.tsx        # 应用主题样式
│           └── TopicDetail.tsx    # 应用主题样式
```

### 4.2 核心实现思路

1. **创建 ForumThemeContext**：管理论坛主题状态 (`theme`, `toggleTheme`)
2. **定义主题样式映射**：创建工具函数，根据当前主题返回对应的 Tailwind 类名
3. **组件样式适配**：论坛子组件通过 `useForumTheme` Hook 获取当前主题，动态应用样式
4. **持久化集成**：在 Context 初始化时读取 localStorage，切换时写入 localStorage

### 4.3 关键依赖

| 依赖             | 用途           |
| ---------------- | -------------- |
| React Context    | 状态管理       |
| localStorage API | 主题偏好持久化 |
| lucide-react     | Sun/Moon 图标  |

## 5. 验收标准

### 5.1 功能验收

- [ ] 论坛页面默认使用**浅色主题**
- [ ] 点击 Header 主题切换按钮可在**深色/浅色之间切换**
- [ ] 深色主题下，所有论坛组件（Header、Sidebar、ForumList、TopicDetail）样式与首页风格一致
- [ ] 浅色主题下，所有论坛组件保持当前样式不变
- [ ] **刷新页面**后主题偏好保持不变
- [ ] **关闭浏览器重新打开**后主题偏好保持不变
- [ ] 主题切换时有**平滑过渡效果**，无突兀闪烁

### 5.2 边界条件

- [ ] localStorage 不可用时（隐私模式），功能正常但不持久化
- [ ] 首次访问时（无 localStorage 记录），默认使用浅色主题
- [ ] 首页和其他页面不受论坛主题设置影响
