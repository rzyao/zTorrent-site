# 论坛页面 (ForumPage) 功能总结

## 1. 概述
论坛页面是用户交流、分享资源和讨论的核心区域。该页面集成了板块浏览、帖子列表展示、帖子详情查看、发布新帖以及回复互动等功能。页面采用 React 构建，结合后端 API 实现数据的动态加载与交互。

## 2. 核心功能

### 2.1 浏览与导航
*   **板块分类**：
    *   动态从后端获取板块列表（API: `ForumCategoriesService`）。
    *   支持点击不同板块进行帖子筛选。
    *   包含一个虚拟的“全部”板块，展示所有板块的帖子。
*   **帖子列表**：
    *   展示帖子标题、作者、回复数、查看数、最后回复时间。
    *   **高亮与标记**：支持后端返回的样式标记（加粗、标红）以及“热帖”徽章。
    *   **搜索**：提供搜索框，支持按关键词搜索帖子。
    *   *注：当前页面实现了分页的状态管理（page/limit），但 UI 上暂未显示分页控制器，默认为无限滚动或单页显示。*

### 2.2 帖子详情
*   **内容展示**：
    *   点击帖子进入详情页。
    *   展示标题、作者信息、发布时间、浏览量。
    *   **内容渲染**：支持 Markdown/HTML 渲染，包含自定义样式的标题、代码块、引用、图片（带尺寸限制与安全过滤）和链接。
*   **浏览量统计**：
    *   **防刷机制**：利用 LocalStorage 记录浏览时间，15分钟内重复访问不计数。
    *   **乐观更新**：点击时前端先增加浏览数，提升体验。
    *   **API 上报**：调用 `/forum/threads/inc-views` 接口上报浏览数据。支持 `navigator.sendBeacon` 在页面隐藏时补发请求。

### 2.3 互动系统
*   **发布新帖**：
    *   提供弹窗式发布表单。
    *   字段：选择板块（必选）、标题、内容（富文本）。
    *   发布成功后自动跳转至新帖所在列表并刷新。
*   **回复帖子**：
    *   底部提供富文本编辑器用于回复当前主题。
    *   **引用/楼中楼**：点击楼层回复按钮，可对特定回复进行引用回复。
    *   **查看原回复**：对于引用回复，支持点击“查看原回复”跳转至对应楼层，并高亮显示。
    *   **锁定状态**：若主题被锁定，隐藏回复功能并提示用户。

### 2.4 内容渲染与安全
*   **ContentPreview 组件**：
    *   负责帖子主内容的渲染。
    *   样式：使用 Tailwind Typography (`prose`) 配合自定义正则替换，美化 Markdown 元素。
*   **ReplyContent 组件**：
    *   负责回帖内容的渲染，样式更为紧凑。
    *   **引用优化**：针对引用块中的图片进行尺寸限制（max-height: 160px），防止破坏布局。

## 3. 技术实现细节

### 3.1 数据交互
页面主要依赖以下自动生成的 API 服务：
*   **ForumCategoriesService**: 获取板块列表。
*   **ForumThreadsService**: 获取主题列表、主题详情、发布主题。
*   **ForumPostsService**: 获取回帖列表、发布回帖。
*   **Helper Functions**:
    *   `unwrapResponse`: 统一处理后端响应结构，提取 data 字段。
    *   `extractErrorMessage`: 统一错误信息提取，兼顾 OpenAPI 错误对象与普通 Error。

### 3.2 状态管理
使用 React `useState` 和 `useEffect` 管理复杂的页面状态：
*   `activeCategoryId`: 当前选中的板块 ID。
*   `selectedThread`: 当前选中的主题对象（控制列表页/详情页切换）。
*   `threads` / `posts`: 帖子与回帖列表数据。
*   `replyParentId`: 当前正在回复的目标父 ID（用于楼中楼）。

### 3.3 性能与体验优化
*   **防抖/节流**：浏览量统计具备 TTL 限制。
*   **乐观 UI**：浏览数增加即时反馈，无需等待接口返回。
*   **本地存储同步**：利用 `storage` 事件监听，跨标签页同步浏览状态。

## 4. 待优化/注意项
*   列表页暂未发现显式的分页组件（如“上一页/下一页”按钮），可能仅展示第一页或需补充无限滚动逻辑。
*   点赞功能目前仅有 UI 按钮，尚未绑定后端 API。
