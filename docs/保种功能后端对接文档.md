# 保种功能后端对接文档

> 关联页面：`src/pages/SeedingPage.tsx`
>
> 设计目标：为前端保种列表与统计卡片的现有交互提供统一、可扩展的后端接口规范，覆盖保种种子列表、统计概览、分页/筛选/排序/搜索、状态与奖励字段等。

## 统一约定
- Base URL：`/api`
- 认证方式：HTTP 头 `Authorization: Bearer <token>`（未授权返回 401）
- Content-Type：`application/json`
- 时间单位：时长统一采用秒（number），前端自行格式化展示（如“32天15小时”）
- 大小单位：后端统一使用字节（bytes），前端自行格式化展示为 `GB/TB`
- ID 类型：字符串（UUID），由后端生成
- 分页参数：`page`（默认 1）、`limit`（默认 20，最大 100）、返回 `total/total_pages`
- 排序参数：`sort_by`（如 `bonus/ratio/seed_time`）、`sort_order`（`asc`/`desc`）
- 统一响应结构：
  ```json
  { "code": 0, "message": "OK", "data": { ... }, "pagination": { "total": 0, "page": 1, "limit": 20, "total_pages": 0 }, "trace_id": "string" }
  ```
  - 失败示例：`{ "code": 401, "message": "Unauthorized", "trace_id": "string" }`
- 错误码：400（参数错误）、401（未认证）、403（无权限）、404（未找到）、429（限流）、500（服务端错误）

## 核心数据模型
- TorrentSeeding（保种种子）
  ```json
  {
    "id": "string",
    "title": "string",
    "category": "string",
    "poster_url": "https://...",
    "size_bytes": 920463972352,
    "uploaded_bytes": 1684234844160,
    "downloaded_bytes": 252706831360,
    "ratio": 6.67,
    "seed_time_seconds": 2817600,
    "seeders": 45,
    "leechers": 12,
    "status": "normal | warning | good",
    "bonus_total": 156.8,
    "bonus_per_day": 5.0,
    "created_at": "2025-12-10T10:00:00Z",
    "updated_at": "2025-12-10T10:00:00Z"
  }
  ```
  - 说明：为保证排序与统计准确性，后端统一返回数值字段（秒/字节/浮点），前端负责格式化人类可读字符串。

## 状态与奖励计算（建议）
- `ratio`：后端按 `uploaded_bytes / max(downloaded_bytes, 1)` 计算，返回保留两位小数。
- `status`：后端按站点策略生成，建议：
  - `good`：`ratio >= 1` 且 `seed_time_seconds >= 7*24*3600` 或 `seeders >= 30`
  - `warning`：`ratio < 1` 或 `seed_time_seconds < 7*24*3600`
  - `normal`：其他情况
- `bonus_total/bonus_per_day`：后台统一计算与返回；前端用于“累计奖励”和“+X/天”。

## 接口分组与定义

### 保种列表
- `GET /api/seeding/torrents`
- 认证：必需
- Query：
  - `page`（默认 1，最小 1）
  - `limit`（默认 20，最小 1，最大 100）
  - `sort_by`（默认 `bonus`）：`bonus | ratio | seed_time | uploaded | downloaded | size | seeders | leechers`
  - `sort_order`（默认 `desc`）：`asc | desc`
  - `category`（可选）：按分类过滤（如“电影”）
  - `status`（可选）：`normal | warning | good`
  - `q`（可选）：标题关键词模糊搜索
  - `ratio_min`（可选）：最小分享率
  - `seed_time_min`（可选）：最小做种时长（秒）
- Response：`{ code, message, data: { items: TorrentSeeding[] }, pagination, trace_id }`

### 统计概览
- `GET /api/seeding/stats`
- 认证：必需
- Query（可选）：与列表过滤项一致（`category/status/q/ratio_min/seed_time_min`），用于按当前筛选范围统计。
- Response：`{ code, message, data: { total_count, total_bonus, average_ratio, total_uploaded_bytes, total_downloaded_bytes? }, trace_id }`
  - `total_count`（integer）：总做种数
  - `total_bonus`（number）：累计奖励（金币）
  - `average_ratio`（number）：平均分享率（建议简单平均与前端一致）
  - `total_uploaded_bytes`（integer）：总上传量（字节）
  - `total_downloaded_bytes`（integer，可选）：总下载量（字节）

## 字段与验证规则
- `id`：必填；`uuid` 格式
- `title`：必填；长度 1–512
- `category`：可选；建议枚举化管理
- `poster_url`：可选；`https` URL
- `*_bytes`：必填；整数、单位字节、>=0
- `ratio`：后端计算；保留 2 位小数返回
- `seed_time_seconds`：必填；整数、>=0
- `seeders/leechers`：必填；整数、>=0
- `status`：枚举校验；后端生成
- `bonus_total/bonus_per_day`：必填；数值、>=0；保留 1 位小数以匹配前端展示

## 对接注意事项
- 列表与统计支持相同过滤条件，确保“统计卡片”可反映当前筛选上下文。
- 前端排序项为“奖励/分享率/做种时间”，后端对应 `sort_by=bonus/ratio/seed_time`，统一使用数值字段排序。
- 海报目前来自 Unsplash 占位；正式对接后使用后端返回的 `poster_url`。
- 启用 CORS 并限制来源到前端站点；所有接口仅允许 `https`。
- 建议开启用户级限流（`429`），并返回 `Retry-After` 头以便前端重试提示。
