# 论坛浏览次数验证指南

## 验证目标
- 进入主题详情时浏览数递增并实时刷新显示。
- 短时间内重复进入同一主题不会重复计数（15 分钟 TTL）。
- 在未配置后端 BASE 的开发环境，保留乐观 +1 以验证前端逻辑；配置 BASE 时真实调用统计接口。
- 回帖的本地浏览计数在“查看原回复”时递增并展示。

## 验证步骤
1. 打开页面 `论坛`，点击任意主题进入详情，观察头部 `查看` 数字：
   - 首次进入：数字应较列表值增加（后端在详情内递增或显式统计成功）。
   - 刷新页面或返回再进入：若在 15 分钟内，应不再增加。
2. 清除本地防重复标记：在浏览器控制台执行 `localStorage.clear()` 或仅移除 `forum:viewed:<threadId>` 键。
   - 再次进入同一主题详情：`查看` 数字应再次增加。
3. 跨标签页测试：在标签页 A 进入详情，随后在标签页 B 打开同一详情：
   - 标签页 B 不应再次增加计数（存储事件同步）。
4. 配置后端 BASE（`OpenAPI.BASE` 非空）后测试网络异常：
   - 断网或端点不可达时，UI会回滚乐观 +1 并提示错误；恢复网络后正常递增。
5. 回帖本地计数：展开某回复的“查看原回复”交互：
   - 被查看的原回复右侧 `查看` 数字应 +1。

## 常见问题
- 若后端已在 `GET /forum/threads/get-thread`（前端为 `POST /forum/threads/get-thread`）内置递增，前端仅同步返回值即可，无需显式统计接口。
- 若后端尚未提供统计端点，请实现 `POST /forum/threads/inc-views` 并返回最新 `viewsCount`；前端已对接相应 SDK 方法。
