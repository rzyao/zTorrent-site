## 目标
- 在“种子详情弹窗”内任意位置右键，弹出 Context Menu，并提供“下载种子”菜单项。
- 复用已有下载逻辑 `useTorrentDownload` 的 `downloadByTorrentId`，与现有按钮行为一致。
- 根据权限 `access.permissions` 控制菜单项可用性，与按钮一致。

## 关键位置
- 详情内容组件：`src/pages/TorrentDetailPage/index.tsx`
  - 下载按钮现有实现参考：`src/pages/TorrentDetailPage/index.tsx:333`
  - 下载 Hook 引入位置：`src/pages/TorrentDetailPage/index.tsx:44`
- 上下文菜单组件：`src/components/ui/context-menu.tsx`（已封装 Radix Context Menu）：导出 `ContextMenu`、`ContextMenuTrigger`、`ContextMenuContent`、`ContextMenuItem` 等。

## 方案设计
- 在 `TorrentDetailPage` 的根容器外包裹 `ContextMenu`，将根 `div` 作为 `ContextMenuTrigger asChild`，右键触发菜单。
- 在同级渲染 `ContextMenuContent`，包含一个 `ContextMenuItem`：“下载种子”。
- 事件使用 Radix 推荐的 `onSelect`，阻止默认行为后调用 `downloadByTorrentId(String(torrentData.id), String(torrentData.title || 'download'))`。
- 当无权限或无有效 `torrentData.id` 时禁用该菜单项（与按钮的禁用逻辑一致）。

## 改动步骤与原因
1. 引入上下文菜单组件（原因：当前项目已有封装但未使用，需要在详情页使用）
   - 在 `index.tsx` 顶部新增：`import { ContextMenu, ContextMenuTrigger, ContextMenuContent, ContextMenuItem, ContextMenuSeparator } from '@/components/ui/context-menu';`
2. 包裹详情页根容器（原因：使整个详情内容区域右键可触发菜单，符合“在详情弹窗右键”的需求）
   - 使用 `<ContextMenu>` 包裹，`<ContextMenuTrigger asChild>` 包裹最外层 `div.min-h-screen ...`。
3. 渲染菜单内容（原因：提供“下载种子”入口，复用统一下载逻辑）
   - 在 `<ContextMenuContent>` 中放置 `<ContextMenuItem>`，`onSelect` 中调用 `downloadByTorrentId`。
   - 设置 `disabled={!access?.permissions?.includes('download_torrent') || !torrentData.id}`（原因：与按钮一致的权限与数据校验）。
4. 保持现有 UI 与行为不变（原因：上下文菜单仅作为额外入口，不影响原有按钮和布局）。

## 代码草案（含详细注释）
```tsx
// 新增引入：复用项目已封装的 Context Menu 组件
import {
  ContextMenu,
  ContextMenuTrigger,
  ContextMenuContent,
  ContextMenuItem,
  ContextMenuSeparator,
} from '@/components/ui/context-menu';

export default function TorrentDetailPage({ torrentId }: TorrentDetailPageProps) {
  // 已有：统一下载 Hook，按钮与右键菜单均复用该方法
  const { downloadByTorrentId } = useTorrentDownload({
    onInfo: (m) => console.info(m),
    onError: (m) => alert(m),
  });
  const { access } = useAccess();
  // ... 其他状态与数据加载省略

  return (
    // 1) 在详情页根部包裹 ContextMenu，使其成为右键触发的区域
    <ContextMenu>
      {/* 2) 使用 asChild 将最外层容器作为触发器，Radix 在右键时自动显示菜单 */}
      <ContextMenuTrigger asChild>
        <div className="min-h-screen bg-[#0F171E] pt-16">
          {/* 原有详情内容不变 */}
          {/* ... */}
        </div>
      </ContextMenuTrigger>

      {/* 3) 菜单内容：提供“下载种子”入口 */}
      <ContextMenuContent className="w-48">
        {/*
          使用 onSelect（Radix 推荐）而非 onClick，确保在键盘/鼠标选择时一致触发。
          调用统一下载方法，并与按钮保持同样的权限与禁用逻辑。
        */}
        <ContextMenuItem
          disabled={!access?.permissions?.includes('download_torrent') || !torrentData.id}
          onSelect={(e) => {
            e.preventDefault(); // 防止默认菜单选择导致页面滚动或失焦
            if (access?.permissions?.includes('download_torrent') && torrentData.id) {
              // 复用按钮逻辑：以标题作为文件名回退
              downloadByTorrentId(String(torrentData.id), String(torrentData.title || 'download'));
            }
          }}
        >
          {/* 图标与文案与按钮一致，用户感知统一 */}
          <Download className="w-4 h-4 mr-2" /> 下载种子
        </ContextMenuItem>
      </ContextMenuContent>
    </ContextMenu>
  );
}
```

## 权限与异常处理
- 与按钮一致：缺少 `download_torrent` 权限时，菜单项禁用。
- `torrentData.id` 不存在时禁用，避免触发无效下载。
- 下载过程中错误提示复用 `useTorrentDownload` 的 `onError`，确保统一提示。

## 验证
- 打开任一种子卡片“详情”，在弹窗内任意位置右键应出现菜单。
- 有权限：点击“下载种子”触发下载，与按钮行为一致。
- 无权限：菜单项不可用（半透明且不可交互）。
- 在图片、文本、折叠区域等不同位置右键，均能弹出菜单。

## 影响面
- 仅对 `TorrentDetailPage` 增加右键菜单，不影响其他页面；`AnimatedAlertDialogContent` 与列表页逻辑保持不变。
