## 接口与统一响应
- 客户端：沿用 OpenAPI 生成服务（`src/api/services/*`），自动注入 `Authorization: Bearer <token>`。
- 解包策略：与现有代码保持一致（参考 `src/hooks/useApi.ts:118`、`src/stores/dictionaryStore.ts:71-73`）。
  - 逻辑：`const body = hasCode ? response : response.data; const data = body?.data ?? body;`。
- 使用的服务与方法：
  - 板块：`ForumCategoriesService.forumCategoriesControllerList({ page, limit, enabled, search })`
  - 主题：
    - 列表：`ForumThreadsService.forumThreadsControllerList({ page, limit, categoryId, search })`
    - 详情：`ForumThreadsService.forumThreadsControllerGet({ id })`
    - 创建：`ForumThreadsService.forumThreadsControllerCreate({ categoryId, title, content })`
  - 回帖：
    - 列表：`ForumPostsService.forumPostsControllerList({ threadId, page, limit })`
    - 创建：`ForumPostsService.forumPostsControllerCreate({ threadId, content, parentId? })`

## 页面改造点（文件：`src/pages/ForumPage.tsx`）
- 分类导航：
  - 替换硬编码 `categories` 为后端板块列表（启用 `enabled=true`，按 `sort ASC` 前端排序）。
  - 保留一个虚拟“全部”项（`id='all'`）用于不筛选 `categoryId`。
  - 搜索框透传为主题列表的 `search` 字段。
- 主题列表：
  - 用 `forumThreadsControllerList` 填充列表；分页参数 `page`、`limit` 来自本地状态。
  - 不再使用本地 `isPinned/isHot/isElite`，改为映射后端 `highlightMeta.status`：
    - `bold` → 标题加粗（`font-bold`）
    - `red` → 标题红色（`text-red-400`）
    - `badge:hot` → 角标“热帖”（`<Badge>` 显示 Hot）
  - 置顶：后端已在列表排序中优先置顶，无需前端再排序；若需显示“置顶”标识，后续可拓展批量查询 stickies（当前版本不做 N+1 请求）。
- 主题详情：
  - 点击列表项后调用 `forumThreadsControllerGet` 展示首帖内容与基础元数据（浏览数、回复数、最后回帖时间）。
  - 根据 `status` 控制交互：`locked` → 禁止普通用户回帖（置灰输入框并提示）。
- 回帖列表与回复：
  - 调用 `forumPostsControllerList` 按 `createdAt ASC` 分页渲染。
  - 发送回复用 `forumPostsControllerCreate`；成功后刷新当前页列表。
  - 预留 `parentId` 支持楼中楼（UI 初版不展示层级结构，仅保留接口参数以扩展）。
- 发布新帖表单：
  - 分类下拉使用板块列表的 `id/name`。
  - 提交调用 `forumThreadsControllerCreate`；成功后关闭表单并刷新线程列表到第 1 页。
  - 限流与错误提示见下节。

## 错误与限流提示
- 统一失败判定：`body?.code !== 1000` 视为失败，UI 显示 `body?.message || 通用错误文案`。
- 典型错误处理：
  - `429`（命中限流）：显示后端返回的 `message`（如“发帖过于频繁，请稍后再试”/“回帖过于频繁...”）。
  - `9401`（未认证）：提示登录失效并引导重新登录（路由守卫已阻止匿名访问）。
  - `9403`（无权限）：提示“无权限或访问被拒绝”。
  - `9404`（资源不存在）：提示并关闭详情抽屉。
- 行为：错误信息置于页面顶端 `Alert` 或局部 `Toast`；限流命中后按钮进入短暂 `disabled` 并显示倒计时（可选）。
