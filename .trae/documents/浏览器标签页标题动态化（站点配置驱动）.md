## 目标
- 将浏览器标签页标题统一改为：`{site.logo.url} {site.title} {页面名} {架构信息}`。
- 所有变量从系统配置接口读取，缺失则按空串处理并自动去除多余空格。
- 保持页面切换时标题自动更新；失败时回退到 `index.html` 的静态标题。

## 数据来源
- 使用 `SettingsService.settingsControllerListSettingsByGroup({ group: 'site' })` 拉取站点组配置。
- 预期键：`site.title`、`site.logo.url`、`site.arch`（或 `site.architecture`）。若后端暂未提供“架构信息”，先按空串处理。
- API 基址与鉴权沿用 `src/layouts/AppLayout.tsx` 的 `OpenAPI.BASE`、`OpenAPI.TOKEN` 设置。

## 技术实现
- 新增 `SiteConfigContext`（`src/context/SiteConfigContext.tsx`）：
  - 负责首屏拉取 `site` 组配置，提供 `title`、`logoUrl`、`archInfo` 三项状态给全局。
  - 放置 Provider 于 `src/layouts/AppLayout.tsx`，确保全站可用。
- 新增工具函数 `composeTitle({ logoUrl, title, archInfo }, pageName)`（`src/utils/title.ts`）：
  - 以顺序拼接并清理空串、重复空格，得到最终 `document.title` 文本。
- 新增 Hook `useDynamicTitle(pageName: string)`（`src/hooks/useDynamicTitle.ts`）：
  - 读取 Context 数据，在页面挂载与依赖变化时调用 `document.title = composeTitle(...)`。
- 页面接入：在各页面组件顶层调用 `useDynamicTitle('中文页面名')`。
  - 例如：`UploadTorrentPage`→`上传`，`HomePage`→`首页`，`TorrentsPage`→`种子`，`ForumPage`→`论坛` 等。
- 可选集中管理：在 `AppLayout` 中根据 `useLocation()` 做 `path→页面名` 映射，作为默认值；页面内传入值优先生效。

## 代码改动点
- `src/layouts/AppLayout.tsx`：
  - 引入并包裹 `SiteConfigContext.Provider`；首屏触发配置拉取。
- `src/hooks/useDynamicTitle.ts`：
  - 新增 Hook，实现标题更新副作用。
- `src/utils/title.ts`：
  - 新增标题拼接与清理工具。
- 各页面 `src/pages/*Page.tsx`：
  - 顶层调用 `useDynamicTitle('页面名')`，不做旧代码兼容。
- `index.html`：无需修改；运行时将覆盖静态 `<title>`。

## 验证方案
- 本地启动后访问多个页面，确认标题形如：`http://logo.url 站点标题 上传 架构信息`。
- 断网或接口报错时，标题维持 `index.html` 默认值；接口恢复后自动更新。
- 将配置中任一键置空，检查拼接无多余空格或分隔符。

## 风险与回退
- 接口不可用或缺少“架构信息”键时，标题仍正常（缺项为空处理）。
- 如后端键名与预期不同，可在 Context 中做一次性键映射调整，无需改动页面。

## 后续可选增强
- 若需要声明式管理标题，可后续引入 `react-helmet-async`；当前版本依赖最小化，直接使用 `document.title`。
