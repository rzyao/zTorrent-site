## 问题分析
- 回帖输入时更新父组件状态，导致帖子详情整体重新渲染；包含 `dangerouslySetInnerHTML` 的原帖内容区域每次键击都会被重建，图片随之重新加载。

## 解决方案
- 将帖子正文渲染提取为独立、可记忆的组件，避免与回复编辑状态耦合：
  - 新增 `ContentPreview`（React.memo），只在正文内容字符串变化时才更新。
  - 使用 `useMemo` 预计算 HTML（基于 `threadDetail?.content` 与 `selectedThread?.content`），减少不必要计算。
- 在帖子详情处用 `<ContentPreview html={contentHtml} />` 替换原 `dangerouslySetInnerHTML` 的 `div`。

## 实施步骤
1. 在 `src/pages/forum/ForumPage.tsx`：
   - 更新导入：`import { useEffect, useMemo, useState, memo } from 'react'`。
   - 新增组件：`const ContentPreview = memo(({ html }) => <div ... dangerouslySetInnerHTML={{ __html: html }} />)`，复用原样式类名。
   - 新增 `const contentHtml = useMemo(() => renderPreview(threadDetail?.content ?? selectedThread.content), [threadDetail?.content, selectedThread?.content])`。
   - 替换原正文渲染 `div` 为 `<ContentPreview html={contentHtml} />`。

## 验证
- 在帖子详情中输入回复时观察：原帖内容与图片保持稳定不闪烁、不重载；仅回复编辑区域更新。
- 切换不同帖子或展开/收起时，正文正确更新显示。

## 说明
- 此改动隔离渲染域，显著降低不必要的 DOM 重建。
- 若后续需要进一步优化，可以对截图区域或其他静态块同样做 memo 封装。
