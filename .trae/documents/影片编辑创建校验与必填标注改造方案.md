# 目标
为“影片编辑-添加新影片”增加必填字段标注与提交前校验，保证数据质量并与后端校验规则一致（成功码=1000，字段规范遵循统一对接文档）。

## 校验规则（与后端一致）
- 必填：
  - `title`（影片中文标题）
- 强校验：
  - `year` 格式 `YYYY` 或 `YYYY-YYYY`（如 `2014`、`2011-2019`）
  - `category` 为枚举（`电影/剧集/纪录片/动漫` → 映射 `film/series/documentary/anime`）
  - `rating` 范围 0–10（包含两端）
- 合法性（若填写则校验）：
  - `poster/backdrop` 必须为 `http/https` URL
  - `genres[]`、`cast[]` 长度 ≤ 20，元素去重、去空白

## UI标注（新增）
- 在表单标签处以红色 `*` 明示必填项：`标题(title)`
- 在可能阻断保存的强校验项旁添加“必填/格式”提示：`年份(year)`（格式）、`类别(category)`（枚举）
- 为出现错误的输入加红色边框与下方错误文案（统一样式，不引入新库）
- 保存按钮：当存在未通过校验时禁用并显示提示（保留现有 `!movieForm.title` 的禁用逻辑，扩展为综合校验）

## 代码改造点
- 文件：`src/pages/edit/EditMoviePage.tsx`
1) 状态与工具函数
- 新增 `errors` 状态对象：`{ title?: string, year?: string, category?: string, rating?: string, poster?: string, backdrop?: string }`
- 新增 `validateFilmForm(form)`：返回 `{ valid: boolean, errors }`
- 新增 `isValidUrl(url)` 与 `isValidYear(year)`、`isValidRating(rating)` 辅助函数

2) 交互与提交流程
- `onChange`：清理对应字段的错误（即时反馈）
- `handleSaveMovie`：在调用后端前执行 `validateFilmForm`；若无效，设置 `errors` 并阻止提交
- 保存按钮禁用条件扩展：`!movieForm.title || hasErrors`

3) 视觉与可访问性
- 在 `label` 文本后追加 `*`（仅必填项）；为错误字段增加红色边框类与 `aria-invalid="true"`
- 在输入下方渲染错误文案（简短、明确，如“标题为必填”、“年份格式应为YYYY或YYYY-YYYY”）

## 说明与理由
- 与后端校验一致：避免前后端重复交互导致的用户体验问题
- 先客户端拦截：减少无效请求与错误码弹窗频率
- 可扩展：保留 Hook 与服务对接逻辑不变，仅在页面表单层新增校验与视觉标注

## 验证与联调
- 手工验证：
  - 标题为空→保存禁用并提示
  - 年份不合法→提示并禁用；改正后允许保存
  - URL 不合法→提示但允许清空恢复
  - 成功保存→后端返回 `code=1000`，页面同步详情
- 失败模拟：后端返回非 `1000`→仍显示后端错误（现有 `alert` 机制保留）

- 更新 `EditMoviePage.tsx`：新增校验逻辑与错误提示、必填标注
- 保持现有 `useFilms` 与后端请求流程，无引入新依赖
